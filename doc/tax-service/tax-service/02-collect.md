## 2. S05-02 자료 올리기

### 자료 카드 8장 (4열 × 2행)

| 자료 | 받는 파일 | 기관 선택 |
|---|---|---|
| 매입·매출 계산서 | 홈택스 전자세금계산서·계산서 목록 엑셀 **그대로** | — |
| 카드 사용 내역 | 카드사 엑셀 → 표준양식 | 국민카드 · 우리카드 → 카드 |
| 현금 경비 | 표준양식 (항목 칸 있음) | — |
| 은행 입출금 | 은행 엑셀 → 표준양식 | 국민 · 우리 · 하나은행 → 계좌 |
| 급여대장 | 표준양식 (소득 구분 칸, 주민번호 없음) | — |
| 국세 납부 | 홈택스 납부내역 엑셀 (세목 칸) | — |
| 지방세 납부 | 위택스 납부내역 엑셀 (세목 칸) | — |
| 대출 내역 | 표준양식 (원금 · 이자 칸) | — |

카드 상태: `N개 파일`(인디고) · `쓰지 않는 자료`(회색, 세무 설정 링크) · `이번 달 없음`(회색, [되돌리기]) · `아직`(회색, [이번 달 없음]).
표준양식 칸 정의는 `07-data-model.md#1`.

### 「이번 달 없음」 · 「쓰지 않는 자료」

| | 범위 | 어디서 |
|---|---|---|
| 이번 달 없음 | **그 달만.** 다음 달로 자동으로 잇지 않음 | 자료 카드의 링크 |
| 쓰지 않는 자료 | 매달 자동으로 「없음」 | 세무 설정 (`05-settings.md#5`) |

둘 다 1단계 「끝남」 판정에서 「없음」으로 셉니다. 파일을 올리면 그 달의 「이번 달 없음」은 풀립니다.

### 업로드 창 (820px)

```
자료 종류 [카드 사용 내역 ▾]  카드사 [국민카드 ▾]  카드 [법인카드 1 · 끝 4821 ▾]
┌ 엑셀 파일을 끌어다 놓거나 고르세요  .xlsx · .xls · 한 번에 한 파일  [파일 고르기] ┐
▎표준양식으로 바꾼 결과                    [전체 14줄] [9월 12줄] [10월 2줄 → 10월에 넣음]
 사용일자 · 결제일 · 적용월 · 가맹점 · 금액 — 앞 5줄
▎중복 의심 2건 — 직접 골라 주세요        같은 날 같은 금액의 정상 거래일 수 있어 자동으로 빼지 않습니다
 09.24 쿠팡(주) 420,000   (○ 넣기 ○ 빼기)
                                               [취소] [12줄 올리기]
```

| 상황 | 처리 |
|---|---|
| 기관을 골랐는데 등록된 계좌·카드 없음 | 「등록된 계좌가 없습니다 · 세무 설정에서 추가」, [파일 고르기] 꺼짐. 「사용 안 함」 계좌는 목록에 없음 |
| **같은 파일** | 막음 — 「이미 올린 파일입니다. ○○ — 10.02 14:08에 올렸습니다. 고친 파일이면 올린 파일을 먼저 지우세요」 |
| **같은 줄** (날짜·내용·금액 같음) | 「중복 의심」으로 보여 주고 줄마다 넣기/빼기. 모두 골라야 [올리기]가 켜짐 |
| 다른 달 줄 섞임 | 거래일(카드는 사용일자)로 나눠 각 달에 넣음. 요약 배지로 안내 |
| 1차 기관이 아닌 파일 | 막고 안내 (기관 추가는 2단계) |

「같은 파일」 판정 기준(파일 해시 / 이름+크기)은 개발 판단.

### 올린 파일 표

`자료 · 기관·계좌 · 파일 이름 · 줄 · 올린 때 · [삭제]`.
삭제 확인 창: 「○○ — N줄이 빠지고, 이 파일로 맺은 짝 N건이 풀립니다. 풀린 은행 줄은 다시 「짝 없음」이 됩니다」.

## 3. S05-03 삐용 경비 가져오기

```
┌ 마지막으로 가져온 때 10.02 14:20                               [↻ 가져오기] ┐
│ 다시 가져오면 새로 결재된 경비를 더하고, 바뀌거나 취소된 경비를 반영합니다    │
[가져왔습니다. 새로 1건 · 바뀜 0건 · 취소됨 0건]
[법인카드로 쓴 경비] [직원 개인 돈으로 쓴 경비] [삐용에서 취소된 경비]   ← 처리 규칙 카드 3장
쓴 날 · 직원 · 내용 · 금액 · 낸 방법 · 처리
```

- 대상: 삐용에서 **결재가 끝난** 경비 중 **사용일**이 작업할 달인 것
- [가져오기]는 몇 번이든 누를 수 있음 — 같은 경비는 갱신, 새 경비는 추가
- 처리 칸: `06-rules.md#3` 표 그대로
- 취소된 경비는 줄을 지우지 않고 회색·취소선 + 「취소됨 · 맺은 짝 풀림」
