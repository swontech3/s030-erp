# 0. 모든 화면 공통

## 0-1. 틀

```
┌ 삐용 메뉴 248px ┬ 삐용 제목줄 62px  「세무 · {화면 이름}」 ─────────────────┐
│ (그리지 않음)   ├ 본문  여백 위 24 · 좌우 36 · 아래 56 / 영역 사이 20px      │
│                │  ① 작업할 달 줄                                            │
│                │  ② 화면 제목 + 설명 (+ 오른쪽 배지)                         │
│                │  ③ 본문 카드들                                             │
│                │  ④ [다음 단계] 줄 (있는 화면만)                              │
└────────────────┴──────────────────────────────────────────────────────────┘
```

- **그리는 범위:** 세무 화면은 본문만 그립니다. 시안은 1280px 틀 안에 그렸고, 왼쪽 메뉴(248px)와 위 제목줄(62px)은 삐용 자리라 빗금으로만 표시했습니다.
- **폭:** 본문 1032px에서 좌우 여백 36px씩을 빼면 내용 폭은 **960px**입니다. 가로 스크롤은 생기지 않습니다.
- **제목줄:** 「세무 · 이번 달 할 일」처럼 표시합니다. 이 줄은 삐용이 그립니다.
- **쓰는 사람:** 화면 11개 모두 **회사**(삐용을 쓰는 고객사)입니다. 시안에 운영사 화면이나 권한별 차이는 없습니다. 권한은 삐용 권한관리가 세무 메뉴 단위로 줍니다.
- **메뉴에서 들어오는 곳:** 삐용 왼쪽 메뉴의 세무 항목입니다(시안에 없음 — 메뉴 이름과 순서는 삐용이 정함).

### 펼침 — 은행 줄 쪽 남은 금액

- **카드:** 「이 은행 줄에 4,400,000원이 남았습니다」(14px 굵게) + 「다른 자료(계산서 등)와 짝을 더 맞추세요. 다 맞춘 뒤에도 남으면 남은 금액만 거래 분류로 넘깁니다 — 돈이 실제로 들어온(나간) 것이라 짝 없는 입금(출금)과 같습니다.」
