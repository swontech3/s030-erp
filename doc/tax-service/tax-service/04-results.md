## 1. S05-07 원천세

제목 아래 풀이: 「원천세 — 월급·외주비를 줄 때 회사가 떼어 대신 내는 세금」 (점선 밑줄 + title).

### 매월 신고 (기본)

```
┌ 신고 기간  2026년 9월 지급분 · 지급일 09.25 · 귀속 9월          10월 10일까지 낼 세금  299,450원 ┐
[근로소득 4명 — 준 돈 · 뗀 소득세 · 뗀 지방소득세]  [사업소득 (3.3%) 1명 — 같은 3줄]
▎9월 급여대장 · 5명      급여대장의 세액을 그대로 씁니다 · 시스템이 다시 계산하지 않습니다
 이름 · 소득 구분 · 귀속월 · 지급일 · 지급액 · 소득세 · 지방소득세
ⓘ 주민번호를 받지 않습니다 — 원천징수이행상황신고서는 합계만, 지급명세서는 세무사가
┌ 신고자료를 만들면 파일로 받거나 세무사에게 함께 보낼 수 있습니다     [신고자료 만들기] ┐
```

| 규칙 | 내용 |
|---|---|
| 기준 달 | **실제로 준 달(지급월).** 귀속월은 열로 함께 표시 |
| 소득 구분 | 급여대장의 「소득 구분」 칸 — 근로 / 사업. 업로드는 한 번 |
| 세액 | 급여대장 값 그대로. 계산하지 않음 |
| 주민번호 | 칸 없음 |
| 만든 뒤 | 파일 줄 「원천징수이행상황신고서_2026-09_지급분.xlsx · 만든 때」 + [다시 만들기] [받기]. 「메일은 세무사 전달에서 정리본과 함께 보냅니다」 |

### 반기납부 (세무 설정에서 체크한 회사)

| 반기 | 묶는 달 | 신고 | 만들기 |
|---|---|---|---|
| 상반기 | 1~6월 지급분 | 7월 10일 | **6월 급여대장을 올리면** [신고자료 만들기]가 켜짐 |
| 하반기 | 7~12월 지급분 | 다음 해 1월 10일 | **12월 급여대장을 올리면** [신고자료 만들기]가 켜짐 |

- 작업할 달이 속한 반기를 보여 줍니다. 안내 띠: 「반기는 둘입니다 — 1~6월분은 6월 급여대장을 올리면, 7~12월분은 12월 급여대장을 올리면 신고자료를 만들 수 있습니다. 지금은 ○○분을 쌓는 중입니다」
- 6칸 달 표: 올린 달은 인디고 배경 + 그 달 세액, 아직은 「아직」
- 낼 세금: **그 반기 누적** (「7~9월 누적 낼 세금」 / 「1~4월 누적 낼 세금」)
- 그 전에는 버튼 꺼짐 + 「6월(12월) 급여대장을 올리면 [신고자료 만들기]가 켜집니다」
- 할 일 5단계는 「조회 · 6월(12월) 급여대장 뒤 만듦」 · 규칙 요약 `06-rules.md#8`

## 2. S05-08 월별 손익

```
설명: 매입·매출은 계산서 날짜, 카드는 쓴 날, 나머지는 거래일 기준이고 부가세는 뺀 금액입니다
┌ 2026년 막대 차트 (1~12월, 번 돈 인디고 · 쓴 돈 회색) — 누르면 그 달로 ┐
[9월 번 돈] [9월 쓴 돈] [9월 남은 돈]
⚠ 아직 빠진 금액이 있습니다. 분류 남은 9줄 (12,013,730원) … · 대출 내역을 올리지 않아 대출 이자가 빠져 있습니다
[번 돈 — 항목별]  [쓴 돈 — 항목별 + 「비용에 넣지 않는 것」]
```

- 조회만. 막대를 누르면 작업할 달이 바뀝니다 (전 화면 공통 달)
- 데이터가 없는 달 막대는 흐리게, 누를 수 없음
- **비용에 넣지 않는 것** (쓴 돈 카드 아래 문구): 카드대금 출금 · 원천세·부가세 납부 · 대출 원금 · 내 계좌끼리 · 대표가 넣은 돈
- 빠진 금액 경고: 분류 남은 줄(금액 합) · 대출 내역이 이 달 없음이고 「쓰지 않는 자료」도 아닐 때

## 3. S05-09 부가세

제목 아래 풀이: 「부가세 — 손님에게 받아 둔 10% 세금에서 내가 낸 10%를 빼고 차액을 냅니다」.

| 사업자 유형 | 신고 기간 표시 | 마감 |
|---|---|---|
| 법인 | 「2026년 3분기 예정신고 · 7~9월」 (예정 · 확정, 분기) | 10월 25일 |
| 개인 일반과세자 | 「2026년 2기 확정신고 · 7~12월」 + 안내 띠 「10월 25일까지 예정고지 금액을 냅니다 — 고지서 금액, 신고 없음」 | 2027년 1월 25일 |

### 낼 세금 예상 (왼쪽 카드)

```
받아 둔 부가세 (매출세액)             7~9월 매출 계산서 공급가액의 10%           6,230,000
계산서 없는 매출 [추정 · 세무사 확인]  분류에서 붙인 입금 330,000원 × 1/11           30,000
                                      면세 품목이면 부가세가 없으므로 세무사가 고칠 수 있습니다
− 낸 부가세 — 매입 계산서 (매입세액)                                        1,480,000
− 낸 부가세 — 카드 사용 [추정 · 세무사 확인]  분류 항목의 「부가세 공제 추정」 칸으로 계산   612,000
━ 낼 세금 예상                                                             4,168,000원
```

| 줄 | 계산 |
|---|---|
| 계산서 없는 매출 | 분류에서 「계산서 없는 매출」로 **확정한** 입금 합계 ÷ 11 (반올림). 없으면 「없음」(회색) |
| 카드 사용 | 카드 줄의 항목이 「부가세 공제 추정 = 예」인 것의 세액 합 (`07-data-model.md#2`) |

### 공제가 안 될 수 있는 매입 (오른쪽 카드, 「추정」)

「시스템이 추정만 하고 판단은 세무사가 합니다. 공제가 안 되면 낼 세금이 **최대 N원** 늘어납니다」 + 항목별 세액. 접대 성격 식대, 업무용이 아닐 수 있는 승용차 등.

맨 아래: 「이 화면은 보기만 합니다. 실제 신고는 세무사가 하며, 숫자는 세무사 전달 때 정리본에 함께 들어갑니다」.

## 4. S05-10 세무사 전달

```
⚠ 보낸 뒤 바뀐 자료가 있습니다. 10.06에 보낸 뒤 자료가 고쳐졌습니다. 다시 보내면 …   ← 해당 시
┌ 보내기 전 확인 [남은 일 2]  남은 일이 있어도 보낼 수 있습니다 · 남은 건수는 메일 본문에
│ [짝 확인 남음 4줄] [분류 남음 9줄] [원천세 신고자료 아직]
[받는 사람 — 세무 설정의 메일, 체크]   [보낼 파일 — 정리본(고정) · 원천세 · 원본 파일 체크]
┌ 메일 미리보기 — 받는 사람 · 제목 · 본문
                                                              [세무사에게 보내기]
▎보낸 이력  보낸 때 · 받는 사람 · 파일 · 남은 일 · 상태(보냄 / 보낸 뒤 바뀜)
```

| 항목 | 규칙 |
|---|---|
| 발송 | **삐용이 이미 쓰는 메일 발송 수단 한 곳.** 새 발송 수단을 만들지 않음 |
| 받는 사람 | 세무 설정의 메일(최대 3), 기본 모두 체크. 0명이면 [보내기] 꺼짐 |
| 정리본 엑셀 | 항상. 시트: 매입·매출 · 카드 · 현금 경비 · 은행(짝·분류) · 급여 · 세금 납부 · 대출 · 삐용 경비 · 거래처 · 손익 · 부가세 |
| 원천세 신고자료 | 만들었으면 함께. 안 만들었으면 꺼진 체크 + 「원천세에서 만들기」 링크 |
| 원본 파일 | 올린 파일 목록에서 고르면 **압축**해서 함께 |
| 남은 일 | 짝 확인 · 분류 · 원천세. 있어도 보냄 — 본문에 「아직 남은 일: …」 |
| 제목 | `[회사명] 2026년 9월 세무 자료` |
| 보내기 | 확인 창 「N명에게 9월 정리본을 보냅니다. 남은 일(…)은 메일 본문에 적힙니다」 |
| 이력 | 최신이 위. 가장 최근 보낸 뒤 바뀌었으면 그 줄 상태 「보낸 뒤 바뀜」 |
