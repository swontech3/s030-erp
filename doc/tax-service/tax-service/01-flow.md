# 업무 흐름 — 세무 서비스 (S05)

**대상:** 세무를 잘 모르는 10인 이하 영세업체·스타트업·초기 사업주 (개인 일반과세자 · 법인)
**목표:** 엑셀로 올린 자료로 월별 손익·부가세를 보고, 정리된 서류를 세무사에게 메일로 넘긴다
**1단계 범위:** 엑셀 업로드 중심. 외부 연동(은행·카드·홈택스 직접 연결)은 2단계

**확정 2026-10-24** — 확정 범위와 변경 이력은 `README.md`. 결정 과정은 `_history/` 에 남겨 두었습니다.

### 작업할 달

모든 세무 화면 맨 위에 **작업할 달 선택기 하나.** 처음 열면 **지난달**. 한 화면에서 바꾸면 다른 세무 화면도 같은 달로 열립니다.
거래처 · 세무 설정은 달과 상관없는 화면이라 선택기 자리에 그 안내만 둡니다.

```
  ① 자료 올리기 ──→ ② 삐용 경비 가져오기 ──→ ③ 은행 짝 맞추기 ──→ ④ 거래 분류

  ⑤ 원천세 신고자료 ← 급여대장만 있으면 됨 (③④를 기다리지 않음)
  ⑥ 손익 · 부가세 확인 ← 조회. 분류가 끝날수록 정확해짐

```

## 한 업무 = 한 화면

| 업무 | 하는 화면 | 다른 화면에서는 |
|---|---|---|
| 엑셀 올리기 · 지우기 (급여대장 포함) | 자료 올리기 | 건수만 보여 주고 링크 |
| 「이번 달 없음」 | 자료 올리기 | — |
| 「쓰지 않는 자료」 (매달 없음) | 세무 설정 | 자료 올리기는 배지 + 「세무 설정」 링크 |
| 삐용 경비 불러오기 | 삐용 경비 가져오기 | — |
| 짝 확정 · 해제 | 은행 짝 맞추기 | 분류 화면에서는 짝을 맺을 수 없음 |
| 항목 붙이기 | 거래 분류 | 짝 맞추기는 「짝 없음 → 거래 분류」 표시만 |
| 거래처 고치기 · 합치기 · 주거래처 | 거래처 | 업로드 때 자동 생성만 |
| 원천세 파일 만들기 · 받기 | 원천세 | 메일은 보내지 않음 |
| 메일 보내기 | 세무사 전달 | — |
| 세무사 메일 · 계좌 · 카드 · 유형 · 반기납부 | 세무 설정 | 업로드 창은 「세무 설정에서 추가」 링크만 |

## 확정된 결정 요약

| 항목 | 결정 | 상세 |
|---|---|---|
| 같은 파일 재업로드 | 막음 | `02-collect.md#2` |
| 같은 줄 | 건너뛰지 않고 「중복 의심 N건」 → 사람이 넣기/빼기 | `02-collect.md#2` |
| 매달 없는 자료 | 세무 설정 「쓰지 않는 자료」 → 매달 자동 「없음」 | `05-settings.md` |
| 법인카드 삐용 경비 | 카드 줄에 증빙 연결만, 비용은 한 번 | `06-rules.md#3` |
| 짝 자동 확정 | 금액·날짜(±3일)·거래처 모두 맞을 때. 「자동」 표시 · 해제 가능 | `06-rules.md#4` |
| 짝 금액 차이 | 1만 원 이하 → 「수수료」 자동 기록 / 넘으면 확정할 때 「나눠서 낸 것(일부 짝)」·「짝이 아님」 선택. 남은 금액은 계산서 쪽이면 분류 안 함, 은행 줄 쪽이면 다 맞춘 뒤 남은 금액만 분류 | `06-rules.md#4` |
| 달을 넘는 짝 | 허용 · 앞뒤 2개월 · 비용은 원래 자료의 달 | `06-rules.md#4` |
| 카드대금 | 결제일로 찾고, 적용월 같은 줄의 청구 합계와 짝. 대금 출금은 비용 아님 | `06-rules.md#4` |
| 분류 항목 | 공통 코드 표 · 입금/출금 구분 · 개인/법인 다름 | `07-data-model.md#2` |
| 손익 날짜 | 계산서 날짜 · 카드 사용일자 · 나머지 거래일 | `06-rules.md#6` |
| 부가세 추정 | 카드 공제 · 계산서 없는 매출(1/11) 모두 「추정 · 세무사 확인」 | `04-results.md#3` |
| 원천세 | 지급월 기준 · 귀속월 표시 · 주민번호 칸 없음 · 반기납부(1~6월분은 6월, 7~12월분은 12월 급여대장 뒤 만들기) | `04-results.md#1` · `06-rules.md#8` |
| 메일 | 삐용이 쓰는 발송 수단 · 받는 사람 최대 3 · 남은 일이 있어도 보냄 | `04-results.md#4` |
| 보낸 뒤 바뀜 | 보낸 파일에 들어가는 값이 바뀔 때만 | `06-rules.md#7` |
