# 정리하기 — 은행 짝 맞추기 · 거래 분류 · 거래처

---

## 1. S05-04 은행 짝 맞추기

```
ⓘ 자동 확정 · 수수료 · 앞뒤 2개월 · 카드대금 규칙 안내 (회색 띠)
┌ [국민은행 · 운영 통장] [하나은행 · 급여 통장]                        ← 계좌 탭
│ (전체 18) (확인 필요 4) (짝 없음 7) (짝 맞춤 7) (그중 자동 6)          ← 필터 칩
│ 날짜 · 내용 · 입금 · 출금 · 짝 · [버튼]
│ 09.01 (주)강남빌딩 임대료      1,650,000  매입 계산서 [자동]      [해제]
│                                         (주)강남빌딩 · 9월 임대료 계산서
│ 09.15 국민카드 결제대금        3,812,000  카드대금 [8월 자료와 짝] [해제]
│ 09.18 브라이트랩  8,800,000              [후보 2개]                [확인]
│   └ ○ 매출 계산서 · 2건 묶음  브라이트랩 · 매출 계산서 2건 합계       8,800,000원
│     ○ 매출 계산서  … 1건만  금액 차이 4,400,000원 — 기준을 넘습니다. 확정할 때 나눠서 낸 것인지 고릅니다
│                                                         [닫기] [짝 확정]
│ 09.24 쿠팡(주)                   420,000  [짝 없음 → 거래 분류]     [짝 찾기]
```

열 너비 `68 · 170 · 112 · 112 · 1fr · 92`.

### 줄 상태

| 상태 | 짝 칸 | 버튼 |
|---|---|---|
| 자동 확정 | 짝 종류(12px) + 상대 이름 + **「자동」** 배지 | [해제] |
| 사람이 확정 | 짝 종류 + 상대 이름 | [해제] |
| 후보 있음 | 「후보 N개」(주황) + 첫 후보 이름 | [확인] (primary) → 펼침 |
| 짝 없음 | 「짝 없음 → 거래 분류」(회색) + 안내(있으면) | [짝 찾기] → 펼침 |

- 다른 달 자료와 맺은 짝: 짝 종류 옆 **「8월 자료와 짝」** 배지
- 차이가 있는 짝: 상대 이름 아래 「차이 500원 → 수수료로 남김」 / 「[일부 짝] 계산서 남은 3,000,000원 — 다른 은행 줄과 짝」
- 은행 줄 쪽에 남은 금액이 있는 「일부 짝」은 「확인 필요」 칩 · 할 일 3단계 건수에 셉니다. 짝 칸의 [남은 금액 처리] → 펼침: 「이 은행 줄에 N원이 남았습니다 — 다른 자료와 짝을 더 맞추세요. 다 맞춘 뒤에도 남으면 남은 금액만 거래 분류로 넘깁니다」 + [남은 금액을 거래 분류로]. 넘긴 뒤 「남은 N원 → 거래 분류로 넘김」
- 짝 없음 안내 예: 「지방세 납부 자료를 올리면 짝이 생길 수 있습니다」 — 그 종류 자료가 이 달에 없을 때

### 펼침

- 후보마다 라디오 카드: 짝 종류(+ 「N건 묶음」 · 「N월 자료와 짝」) · 상대 이름 · 금액 · 차이 문구
- 짝 없음 줄: 자료 없이 고를 수 있는 짝만 — 입금이면 「대표가 넣은 돈」·「내 계좌끼리」, 출금이면 「내 계좌끼리」. 「아니면 그대로 두세요 — 거래 분류에서 항목을 붙입니다」
- [짝 확정]은 하나를 골라야 켜짐. 금액이 다르면 「금액이 다른 짝은 자동으로 확정하지 않습니다. 맞는지 확인하고 확정하세요」
- **차이가 기준(1만 원)을 넘는 후보**를 고르면 아래에 선택 카드:
  ```
  금액 차이 3,000,000원 — 어떤 경우인가요?
  ○ 나눠서 낸 것 — 짝을 맺고, 계산서의 남은 3,000,000원은 다른 은행 줄과 짝을 맞춥니다
  ○ 짝이 아님   — 확정하지 않습니다
  남은 금액은 아직 안 낸 돈이라 비용이 아닙니다 — 비용은 이미 계산서로 잡혀 있습니다.
  ```
  둘 중 하나를 골라야 버튼이 켜지고, 「짝이 아님」이면 버튼 이름이 [확정하지 않음] → 펼침을 닫고 후보로 남김

### 동작

| 동작 | 결과 |
|---|---|
| 짝 확정 | 상태 → 확정. 차이 처리 — 수수료 또는 일부 짝 (`06-rules.md#4`). 분류에 붙인 항목이 있었으면 지움 |
| 해제 | 상태 → 후보 있음 (원래 후보로 돌아감). 수수료 기록 · 일부 짝도 풂 |
| 둘 다 | 「보낸 뒤 바뀜」 대상 |

## 2. S05-05 거래 분류

**대상** — 셋을 한 목록에:
1. 짝 맞추기에서 **짝 없음**인 은행 줄
2. **항목 칸이 빈** 현금 경비 줄
3. **짝 남은 금액** — 은행 줄 쪽에 남은 금액을 짝 맞추기에서 넘긴 것 (출처 「짝 남은 금액」)

계산서 쪽 남은 금액과 1만 원 이하 차이(「수수료」 자동 기록)는 분류 대상이 아닙니다 (`06-rules.md#4`).

```
ⓘ 항목 목록은 공통 코드 표에서 — 법인용 출금 항목 15개 · 입금 항목 8개
┌ (남은 줄 9) (모두 9)                  [3줄 선택] [항목 고르기 ▾] [선택한 줄에 붙이기]
│ ☐ 날짜 · 출처 · 내용 · 금액 · 항목 · [확정]
│ ☐ 09.25 운영 통장 스타벅스 강남R점  54,000 [식대·회의비 ▾]  [확정]
│                                          지난번 항목을 골라 두었습니다
│ ☐ 09.29 운영 통장 현금 매출 입금   +330,000 [입금 항목 고르기 ▾] [확정]
```

열 너비 `44 · 64 · 96 · 1fr · 104 · 250 · 84`.

| 규칙 | 내용 |
|---|---|
| 항목 목록 | **입금 줄엔 입금 항목만, 출금 줄엔 출금 항목만.** 사업자 유형별 목록 (`07-data-model.md#2`) |
| 지난번 항목 | 같은 내용(거래처) 줄에 지난번 항목을 **골라 두기만.** 「지난번 항목을 골라 두었습니다」. 확정은 사람이 |
| 확정 | 항목을 고르면 [확정]이 켜짐. 확정 후 항목 이름 굵게 + [고치기] |
| 여러 줄 한 번에 | 체크 → 항목 → [선택한 줄에 붙이기]. **입금 줄과 출금 줄이 섞이면 막음** 「한쪽만 골라야 한 번에 붙일 수 있습니다」 |
| 잘 모름 | 「잘 모름 — 세무사에게 묻기」도 확정으로 셉니다 (정리본에 그대로 표시) |
| 사업과 무관 | 개인 「사업과 무관 — 대표 인출」 / 법인 「사업과 무관 — 세무사 판단」 |
| 안내 링크 | 「지방세 납부 자료를 올리면 짝이 생길 수 있습니다 · 자료 올리기」 |

입금 금액은 `+330,000` 처럼 앞에 + 를 붙입니다.

## 3. S05-06 거래처

달과 상관없는 하나의 목록. 매입·매출로 나누지 않습니다.

```
⚠ 사업자번호가 같은 거래처가 있습니다. 「브라이트랩」 · 「브라이트랩 주식회사」     [둘 다 고르기]
┌ [거래처명 · 사업자번호      ] (전체 9) (주거래처 4) (일반 5)               [합치기 (2)]
│ ☐ 거래처명 · 사업자번호 · 구분 · 9월 거래 · 처음 생긴 자료 · [고치기]
│ ☐ 브라이트랩  105-86-44521  [(별 아이콘) 주거래처]  3건  매출 계산서  [고치기]
```

| 기능 | 규칙 |
|---|---|
| 자동 생성 | 업로드 때 새 이름이면 「일반」으로 생깁니다. 처음 생긴 자료를 기록 |
| 같은 사업자번호 | 위에 주황 띠로 알림 + [둘 다 고르기] |
| 구분 | 칩 버튼 하나로 주거래처 ↔ 일반. **파일에 안 나오므로 「보낸 뒤 바뀜」 아님** |
| 고치기 | 창: 거래처명 · 사업자번호. 「고친 이름은 모든 달의 자료에 함께 바뀝니다」. 「보낸 뒤 바뀜」 대상 |
| 합치기 | 2곳 이상 고르면 켜짐. 창: **「되돌릴 수 없습니다」 + 각 거래처 건수** + 남길 이름 라디오. 건수는 더하고, 하나라도 주거래처면 주거래처, 사업자번호 없으면 다른 쪽 것 |
| 되돌리기 | 없음 |
