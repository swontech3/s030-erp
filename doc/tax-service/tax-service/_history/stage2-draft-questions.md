# 세무 서비스(S05) — 2단계 : 화면 시안

시안: `handoff/prototypes/s05-tax/index.html`. 위쪽 확인 컨트롤 바에서 화면 11개, 사업자 유형, 원천세 반기납부를 바꿔 볼 수 있습니다.
1단계 목록·흐름(`stage1-screens-questions.md`)은 확정된 그대로 따랐습니다.

- **프레임:** 1280 화면을 기준으로 그렸습니다. 왼쪽 248px 메뉴와 위쪽 제목줄은 삐용이 그리는 자리라 빗금으로만 표시했습니다. 세무 화면이 들어가는 본문은 1032px이고, 좌우 여백 36px을 빼면 내용 폭은 960px입니다.
- **캡처 기준:** **3-2** (본문 규칙은 3-4와 같음 — 확정). 표는 글자를 왼쪽, 숫자를 오른쪽에 두고, 보조 버튼은 흰 바탕입니다.
- **색:** 녹색은 쓰지 않았습니다. 상태 배지는 할 일(회색), 진행 중(주황), 끝남(인디고) 세 가지입니다.
- **시안 날짜:** 시안의 오늘은 2026.10.06 이고, 작업할 달의 기본값은 지난달인 2026년 9월입니다. 데이터는 9월만 있습니다.

## 1단계 답 반영 위치

| 답 | 반영한 곳 |
|---|---|
| A3 회사 기본정보는 삐용이 정본 | 세무 설정 맨 위에 보기 전용으로 표시. 세무 설정에서 받는 값은 유형·세무사 메일·계좌·카드·반기납부뿐 |
| B3 반기납부면 마감일도 반기 기준 | 할 일의 마감 카드 → 「원천세 신고·납부 (반기납부) 1월 10일」 |
| C1 같은 파일은 막고, 같은 줄은 「중복 의심」으로 사람이 고름 | 업로드 창 — 「이미 올린 파일입니다」 안내 / 중복 의심 줄마다 넣기·빼기를 다 골라야 [올리기]가 켜짐 |
| C4 파일 삭제 시 짝 풀림 | 삭제 확인 창에 「짝 N건이 풀립니다」 |
| D1~3 삐용 경비 | 경비 화면 위쪽 카드 3장(법인카드 · 개인 돈 · 취소)과 표의 「처리」 칸 |
| E1 짝 상대 추가 | 4대보험 · 내 계좌끼리 · 대표가 넣은 돈. 자료로 짝이 없는 줄도 [짝 찾기]에서 「대표가 넣은 돈」「내 계좌끼리」를 고를 수 있음 |
| E2 카드대금 = 그 달 청구 합계 | 짝 상대가 「국민카드 4821 · 9월 청구 합계 (38건)」. 손익에 「비용에 넣지 않는 것」으로 적음 |
| E4 자동 확정 표시·해제 | 「자동」 배지와 [해제]. 해제하면 후보로 돌아감 |
| F1 항목은 공통 코드 표 · 개인/법인 다름 | 분류 화면 안내에 「법인용 15개 / 개인용 15개」. 사업자 유형을 바꾸면 목록이 바뀜 |
| F4 사업과 무관 | 개인은 「사업과 무관 — 대표 인출」, 법인은 「사업과 무관 — 세무사 판단」 |
| G1 손익을 잡는 날짜 | 손익 화면 설명 줄 |
| G4 공제 안 되는 매입은 추정만 | 부가세 오른쪽 카드 「추정」 — 「최대 N원 늘어납니다」 |
| H1 주민번호 칸 없음 | 원천세 화면 안내와 급여대장 표에 주민번호 열 없음 |
| H5 지급월 기준 · 귀속월 함께 표시 | 원천세 표의 귀속월·지급일 열 |

## 그리다가 생긴 질문

제안대로 그려 두었습니다. 화면에 **주황 「질문 N」** 표시가 있는 자리입니다.

1. **「이번 달 없음」 표시** (자료 올리기)
   대출이 없는 회사는 대출 내역을 올릴 수 없어서, 그대로 두면 1단계가 끝나지 않습니다.
   제안: 자료 카드마다 「이번 달 없음」을 누를 수 있게 하고, 8종이 모두 「올림」이나 「없음」이면 자료 단계를 끝남으로 봅니다. 「없음」을 다음 달로 이어 갈지도 정해 주세요.
2. **금액이 다른 짝을 확정할 때 차이 금액** (짝 맞추기)
   예: 계산서는 1,100,000원인데 출금은 1,099,500원입니다.
   제안: 차이 500원을 「수수료」 항목으로 자동으로 남깁니다. 차이를 무시할지, 분류로 넘길지도 선택지입니다.
3. **반기납부일 때 원천세 화면** (원천세)
   제안: 매달 금액은 쌓아 보여 주되, 12월 급여대장을 올리기 전에는 [신고자료 만들기]를 끕니다. 할 일의 5단계는 「조회」로 표시합니다.
4. **계좌·카드를 지울 때 이미 올린 자료** (세무 설정)
   제안: 자료는 남기고 「(삭제된 계좌)」로 표시합니다. 그 계좌로 올린 자료가 있으면 지우지 못하게 막을 수도 있습니다.
5. ~~입금 줄 분류~~ → **확정·반영.** 공통 코드 표에 입금/출금 구분 칸. 입금 항목 8개(계산서 없는 매출 · 이자 수입 · 세금 환급 · 보조금 · 지원금 · 대표가 넣은 돈 · 기타 수입 · 잘 모름). 입금 줄엔 입금 항목만. 「계산서 없는 매출」은 부가세 매출에 「세무사 확인」으로 잡힘. 여러 줄을 한 번에 붙일 때 입금·출금 줄이 섞이면 막습니다.
6. ~~달을 넘는 짝~~ → **확정·반영.** 후보는 은행 줄의 달 앞뒤 2개월. 비용·수입은 원래 자료의 달, 은행 줄은 자기 달에서 「짝 있음」. 다른 달과 맺은 짝에 「8월 자료와 짝」 배지 (예: 9월 카드대금 출금 ↔ 8월 사용분 청구 합계).
7. **카드 청구 합계의 기준**
   카드대금 출금과 청구 합계를 맞추려면, 카드 사용 내역 파일에 결제(청구) 월 칸이 있어야 합니다. 1차 카드사(국민·우리) 파일에 그 칸이 있나요? 없으면 사용일 기준 「전월 사용분 합계」로 계산해야 합니다.
8. **부가세의 카드 공제 예상 기준**
   카드 파일에는 가맹점이 과세인지 면세인지 나오지 않는 경우가 많습니다.
   제안: 분류 항목으로 추정합니다(식대·소모품비는 공제, 보험료는 제외 등). 공통 코드 표에 「부가세 공제 추정」 칸을 둡니다.
9. **「보낸 뒤 바뀜」으로 보는 범위**
   제안: 그 달의 자료·짝·분류·거래처·원천세 중 하나라도 바뀌면 표시합니다. 거래처 이름만 고친 것은 빼는 방법도 있습니다.
10. **거래처 합치기 되돌리기**
    제안: 되돌리기 없이 확인 창만 띄웁니다. 합친 뒤 나눠야 할 일이 있나요?

11. ~~계산서 없는 매출의 부가세 계산~~ → **확정·반영.** 입금액의 1/11 (부가세 10% 포함으로 봄). 「추정 · 세무사 확인」 배지 + 「면세 품목이면 부가세가 없으므로 세무사가 고칠 수 있습니다」 한 줄 풀이.
