# 세무 서비스(S05) — 1단계 : 화면 목록 · 흐름 · 질문

**상태: 확정 (화면 목록·흐름).** 질문 답은 반영했고, 시안과 새 질문은 `stage2-draft-questions.md` 에 있습니다.

- 그리는 곳: 삐용 틀의 오른쪽 본문 영역만 그립니다 (1280 화면에서 약 1030px, 가로 스크롤 없음). 좌측 메뉴는 삐용이 그립니다.
- 모든 세무 화면 위쪽에 **작업할 달을 고르는 칸이 하나** 있습니다. 한 화면에서 달을 바꾸면 다른 세무 화면도 같은 달로 열립니다.
- 화면 번호(S05-01 …)는 임시입니다.

## 2. 흐름

```
처음 한 번 ── 세무 설정 (S05-11): 사업자 유형 · 세무사 메일 · 계좌·카드
                │
매달 ───────────┴──────────────────────────────────────────────────────
 이번 달 할 일 (S05-01) — 아래 단계를 카드로 보여 줌. 카드를 누르면 그 화면으로

  ① 자료 올리기 ──→ ② 삐용 경비 가져오기 ──→ ③ 은행 짝 맞추기 ──→ ④ 거래 분류
     (S05-02)          (S05-03)                (S05-04)               (S05-05)
     │                                          짝이 없는 줄만 ④로 넘어감
     │
     └─ 급여대장을 올리면 ──→ ⑤ 원천세 신고자료 (S05-07)   ← ③④를 기다리지 않음

  ⑥ 결과 보기 ── 월별 손익 (S05-08) · 부가세 (S05-09)      ← ③④가 끝날수록 정확해짐

  ⑦ 세무사 전달 (S05-10) ── 보내면 「이번 달 할 일」이 「전달함」으로 바뀜

 거래처 (S05-06) — 정해진 단계가 아니라 언제든 엽니다.
                   ①②에서 새 거래처가 자동으로 생기고, 정리는 이 화면에서만 합니다
```

- 각 화면 아래에 **[다음 단계: ○○]** 버튼을 둡니다. 할 일 화면으로 돌아가지 않아도 순서대로 넘어갈 수 있습니다.
- 단계마다 진행 상태를 **할 일 · 진행 중 · 끝남** 세 가지로 봅니다 (예: 짝 맞추기 「12줄 남음」).
- 앞 단계를 다시 하면(파일 삭제·재업로드 등) 뒤 단계가 어떻게 바뀌는지는 질문 C4, C5 입니다.

## 3. 한 업무 = 한 화면

| 업무 | 하는 화면 | 다른 화면에서는 |
|---|---|---|
| 엑셀 올리기 · 지우기 (급여대장 포함) | 자료 올리기 | 할 일 화면은 건수만 보여 주고 링크 |
| 삐용 경비 불러오기 | 삐용 경비 가져오기 | — |
| 짝 확정 · 해제 | 은행 짝 맞추기 | 분류 화면에서는 짝을 맺을 수 없고 「짝 맞추기로 가기」 링크만 |
| 항목 붙이기 | 거래 분류 | 짝 맞추기 화면은 「분류 필요」 표시만 |
| 거래처 고치기 · 합치기 · 주거래처 지정 | 거래처 | 업로드 때 자동으로 만들어지기만 하고, 다른 화면에서는 편집하지 않음 |
| 원천세 파일 만들기 · 받기 | 원천세 | 급여 자료는 읽기만 |
| 손익 · 부가세 보기 | 각 조회 화면 | 할 일 화면은 숫자 요약만 |
| 메일 보내기 | 세무사 전달 | 원천세 화면은 파일 받기만 하고, 메일은 보내지 않음 |
| 세무사 메일 · 계좌 · 카드 등록 | 세무 설정 | 자료 올리기에서 계좌를 고를 때 「설정에서 추가」 링크만 |

## 4. 질문

질문마다 **제안**을 함께 적었습니다. 맞으면 「제안대로」만 답해 주셔도 됩니다.
**★ 표시는 화면을 그리기 전에 꼭 필요한 답**입니다.

### A. 범위 · 틀

1. ★ **상단 제목줄** — 캡처의 「단체관리」 줄(화면 제목 + 오른쪽 회사명·로그아웃)도 삐용이 그리나요?
   제안: 삐용이 그리고, 세무 화면은 그 아래 본문부터 그립니다.
2. **캡처 기준** — 3-1과 3-2 중 어느 쪽에 맞출까요? 3-2는 표가 왼쪽 정렬이고 다운로드 버튼이 흰색입니다.
   제안: 3-2.
3. ★ **세무 설정 화면** — 1단계에 넣어도 되나요?
4. **사용자** — 회사당 한 명(대표)이 씁니까, 여러 명이 씁니까?
   제안: 권한은 삐용 권한관리에서 세무 메뉴 단위로만 주고, 화면 안에서는 권한 차이를 두지 않습니다.
5. **화면 ID** — 다른 화면처럼 s03… 체계로 번호를 주실 건가요?

### B. 달 · 기간

1. ★ **「이번 달」의 뜻** — 작업할 달(보통 지난달)인가요, 달력상 이번 달인가요?
   제안: 처음 열면 지난달을 보여 주고, 위쪽 칸에서 바꿉니다.
2. **여러 달에 걸친 파일** — 은행·카드 파일 하나에 여러 달 거래가 섞여 있으면 어떻게 할까요?
   제안: 거래일 기준으로 달을 나눠 각 달에 넣습니다.
3. **신고 마감일 표시** — 할 일 화면에 보여 줄까요? (원천세는 매달 10일, 부가세는 사업자 유형별 신고 월의 25일)
   제안: 보여 줍니다.

### C. 자료 올리기

1. **중복 업로드** — 같은 자료를 두 번 올리면 어떻게 할까요?
   제안: 날짜·금액·내용이 같은 줄은 건너뛰고 「중복 N건 제외」라고 알립니다.
2. **1차 기관이 아닌 파일** — 국민·우리·하나은행, 국민·우리카드가 아닌 파일은요?
   제안: 올리지 못하게 막고 안내합니다. 기관은 2단계에서 추가합니다.
3. ★ **매입/매출 양식** — 홈택스에서 내려받는 세금계산서 엑셀 그대로인가요? 계산서·현금영수증·카드매출도 같은 칸으로 올리나요?
4. **파일을 지우면** — 그 파일로 맺은 짝과 분류는 어떻게 되나요?
   제안: 짝을 풀고, 상대 은행 줄은 다시 「짝 없음」으로 돌립니다.
5. ★ **세무사에게 보낸 뒤 수정** — 그 달 자료를 잠그나요?
   제안: 잠그지 않습니다. 고치면 「전달 후 바뀜」을 표시하고 다시 보낼 수 있게 합니다.

### D. 삐용 경비

1. ★ **법인카드 경비** — 법인카드로 쓴 삐용 경비는 카드 내역과 겹칩니다.
   제안: 카드 내역 줄에 증빙으로 연결만 하고, 비용을 두 번 잡지 않습니다.
2. **직원 개인 돈으로 쓴 경비** — 회사가 정산해 주는 이체를 은행 출금과 짝으로 맞추면 되나요?
3. **가져온 뒤 바뀐 경비** — 삐용에서 결재가 취소·수정되면 어떻게 할까요? 그리고 경비가 어느 달에 들어가는지는 결재 완료일과 사용일 중 무엇으로 정하나요?
   제안: 사용일로 정하고, [가져오기]를 다시 누르면 바뀐 내용을 반영합니다.

### E. 은행 짝 맞추기

1. ★ **짝이 되는 상대** — 아래가 맞나요?
   - 출금 ↔ 매입 · 카드대금 · 급여 · 국세 · 지방세 · 대출 상환 · 삐용 경비 정산
   - 입금 ↔ 매출 · 대출 실행
2. ★ **카드** — 카드 사용 건마다가 아니라 「카드대금 출금 1건 ↔ 그 달 카드 청구 합계」로 맞추나요?
3. **한 줄 대 여러 줄 · 금액 차이** — 여러 매출이 한 번에 입금되는 경우와 이체 수수료로 금액이 조금 다른 경우를 허용하나요?
   제안: 한 줄 대 여러 줄은 허용합니다. 금액이 정확히 같을 때만 자동으로 제안하고, 차이가 있으면 사람이 확정합니다.
4. **자동 확정** — 짝을 자동으로 확정해도 되나요?
   제안: 금액 · 날짜(±3일) · 거래처가 모두 맞으면 자동 확정하고, 나머지는 후보로만 보여 줍니다.

### F. 거래 분류

1. ★ **분류 항목 목록** — 시스템이 고정하나요, 세무사가 정하나요? 개인과 법인의 목록이 다른가요?
   제안: 쉬운 말 항목 20개 안팎을 고정으로 두고, 「잘 모름 — 세무사에게 묻기」 항목을 함께 둡니다.
2. **현금경비** — 은행과 짝이 없으니 분류 대상인가요? 업로드 파일에 이미 항목 칸이 있나요?
3. **분류 기억** — 같은 거래처는 다음 달에 자동으로 분류할까요?
   제안: 지난번 항목을 제안만 하고, 확정은 사람이 합니다.
4. **사업과 무관한 출금** — 대표 개인 용도 등은 「사업과 무관」 항목으로 둘까요?

### G. 손익 · 부가세

1. ★ **손익을 잡는 날짜** — 세금계산서 날짜와 돈이 오간 날 중 어느 쪽인가요?
   제안: 매입·매출은 계산서 날짜, 나머지는 거래일로 잡습니다.
2. ★ **대출** — 원금 상환은 비용이 아니고 이자만 비용입니다. 대출 내역 파일에 원금과 이자가 나뉘어 있나요?
3. **국세·지방세 납부** — 원천세·부가세 납부는 비용이 아니고 자동차세·재산세 등은 비용입니다. 파일에 세금 종류가 나오나요?
4. **공제 안 되는 매입** — 접대비, 업무용이 아닌 승용차 등은 사용자가 직접 고르나요, 아니면 「추정」으로만 보여 주나요?
   제안: 「추정」으로만 보여 주고, 판단은 세무사에게 맡깁니다.
5. **부가세 기간** — 법인은 분기, 개인 일반과세자는 반기와 예정고지로 하면 되나요?
6. **4대보험 출금** — 어떤 출금이 회사 부담 4대보험인지 공단 이름으로 자동 인식할까요?

### H. 원천세

1. ★ **주민번호** — 주민번호를 받지 않으면 신고자료에 주민번호 칸이 비게 됩니다. 세무사가 채우나요?
2. ★ **사업소득 3.3% 대상자** — 급여대장과 같은 파일인가요, 별도 양식인가요?
3. **근로소득세** — 급여대장에 이미 계산된 세액을 그대로 쓰나요?
   제안: 그대로 쓰고, 시스템은 계산하지 않습니다.
4. **반기납부 사업자** — 고려해야 하나요?
5. **어느 달 신고인지** — 급여가 속한 달과 실제로 준 달 중 어느 쪽 기준인가요?

### I. 세무사 전달

1. ★ **메일 보내는 방법** — 삐용 「메일 Agent」로 보내나요, 아니면 파일만 만들고 사용자가 직접 보내나요? 문의상담 때 「ERP 메일 발송 기능 없음」이었습니다.
2. ★ **파일 구성** — 엑셀 하나에 시트별로 담나요, 자료별 파일로 보내나요? 처음 올린 원본 파일도 함께 보내나요?
3. **세무사 메일** — 하나만 등록하나요, 여러 개인가요?
4. **덜 끝낸 상태에서 보내기** — 짝·분류가 남은 상태에서도 보낼 수 있게 할까요?
   제안: 보낼 수 있게 하고, 남은 건수를 메일 본문에 적습니다.

## 화면을 그릴 때 지킬 것 (확인용)

- **디자인 시스템:** SwonBiz 디자인 시스템 그대로 씁니다. 녹색은 쓰지 않으며, 「끝남」 상태는 인디고 배지로 표시합니다.
- **용어:** 세무 용어는 쉬운 말을 먼저 쓰고, 꼭 필요한 용어에만 짧은 풀이를 붙입니다 (예: 「원천세 — 월급·용역비를 줄 때 회사가 떼어 대신 내는 세금」).
- **폭:** 본문은 1030px 안에 맞춥니다. 표는 열 수를 줄여 가로 스크롤이 생기지 않게 합니다.
