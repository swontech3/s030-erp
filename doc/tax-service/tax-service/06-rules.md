## 3. 삐용 경비 처리

| 경비 | 처리 | 경비 화면 「처리」 칸 |
|---|---|---|
| 법인카드 | 카드 내역의 같은 줄에 **증빙으로 연결만.** 비용은 카드에서 한 번 | 「카드 내역에 연결됨」 / 「카드 내역에서 못 찾음 — 카드 내역을 더 올리면 다시 찾습니다」 |
| 개인 돈 | 회사 → 직원 **정산 이체 출금**과 은행 짝 | 「정산 이체와 짝 맞춤」 / 「정산 이체 짝 확인 — 짝 맞추기에서」 / 「정산 이체 아직 없음 — 10월 통장에 찍혀도 짝이 됩니다 · 비용은 9월」 |
| 삐용에서 취소 | 「취소됨」으로 남김. 맺은 짝·연결 풀림 | 회색 · 취소선 |

달 기준: **사용일.** 다시 가져오면 바뀐 내용 반영.

## 4. 은행 짝 맞추기

### 짝 상대

| 은행 줄 | 상대 |
|---|---|
| 출금 | 매입 계산서 · 카드대금 · 급여 · 국세 · 지방세 · 4대보험(공단 출금) · 대출 상환 · 삐용 경비 정산 · 내 계좌끼리 |
| 입금 | 매출 계산서 · 대출 실행 · 대표가 넣은 돈 · 내 계좌끼리 |

「대표가 넣은 돈」 · 「내 계좌끼리」는 자료가 없어도 고를 수 있는 짝입니다. 「내 계좌끼리」는 세무 설정에 등록한 계좌 사이만.

### 후보 찾기

- 범위: **은행 줄의 달 앞뒤 2개월** 자료
- 한 줄 대 여러 줄 허용 (예: 매출 계산서 2건 합계 = 입금 1건) — 「N건 묶음」
- 카드대금: 카드 줄의 **결제일**로 찾고, **적용월이 같은 줄의 합계** = 청구 합계

### 자동 확정

금액 · 날짜(±3일) · 거래처가 **모두** 맞을 때만. 「자동」 표시, [해제] 가능. 나머지는 후보.

### 금액 차이

```
차이 = 은행 금액 − 상대 금액
|차이| ≤ 기준 금액 (기본 10,000원, 공통 코드 표 설정값)
    → 확정하면 차이를 「수수료」(출금 항목)로 자동 기록
|차이| > 기준 금액
    → 분류로 넘기지 않습니다. 확정할 때 사람이 고릅니다
       ① 나눠서 낸 것 — 짝을 맺고, 남은 금액은 다른 은행 줄과 짝 (한 줄 대 여러 줄)
                        남은 금액이 있는 쪽은 「일부 짝 · 남은 N원」으로 보입니다
       ② 짝이 아님   — 확정하지 않습니다 (후보로 남음)
```

#### 남은 금액 — 어느 쪽에 남았나

| 남은 쪽 | 예 | 처리 | 거래 분류 |
|---|---|---|---|
| **계산서(자료) 쪽** (은행 < 자료) | 500만 원 계산서에 200만 원만 출금 | 그 계산서가 「일부 짝 · 남은 300만 원」으로 다른 은행 줄의 후보가 됨 | **넘기지 않음.** 아직 안 낸 돈이라 비용이 아님 — 비용은 이미 계산서로 잡혀 있음 |
| **은행 줄 쪽** (은행 > 자료) | 한 출금 ↔ 여러 계산서 | 은행 줄이 「일부 짝」 · 「확인 필요」로 남아 다른 자료와 짝을 더 맞춤 | 다 맞춘 뒤에도 남으면 **남은 금액만 넘김** (출처 「짝 남은 금액」). 돈이 실제로 나간(들어온) 것이라 짝 없는 출금(입금)과 같음 |

은행 줄 쪽 남은 금액은 짝 맞추기에서 [남은 금액 처리] → [남은 금액을 거래 분류로]. 넘긴 뒤에는 「확인 필요」에서 빠지고 짝 칸에 「남은 N원 → 거래 분류로 넘김」.

- 상대가 수수료를 떼고 보낸 입금(입금이 적게 들어온 경우)도 같은 규칙
- 금액이 다른 짝은 **자동 확정하지 않습니다**
- 해제하면 수수료 기록 · 일부 짝 · 분류로 넘긴 남은 금액(붙인 항목 포함)도 풉니다

### 달을 넘는 짝

비용 · 수입은 **원래 자료의 달**(카드 사용일자 · 계산서 날짜 · 경비 사용일)에 잡힙니다. 은행 줄은 자기 달에서 「짝 있음」이 됩니다.
짝 칸에 「8월 자료와 짝」. 상대 자료의 달이 이미 세무사에게 보낸 달이어도 상대 쪽 값은 바뀌지 않으므로 그 달은 「보낸 뒤 바뀜」이 아닙니다.

## 5. 거래 분류

| 대상 | 조건 |
|---|---|
| 은행 줄 | 짝 없음 |
| 현금 경비 | 항목 칸이 비어 있음 (채워져 있으면 그대로 씀) |
| 짝 남은 금액 | 은행 줄 쪽 남은 금액을 넘긴 것 (4번). 계산서 쪽 남은 금액은 대상 아님 |

- 입금 줄 ↔ 입금 항목, 출금 줄 ↔ 출금 항목만
- 지난번 항목 제안: 같은 내용(거래처)의 가장 최근 확정 항목. 확정은 사람이
- 「계산서 없는 매출」은 부가세 매출에도 잡힙니다 (`04-results.md#3`)

## 6. 손익 · 부가세에 잡는 날짜와 범위

| 자료 | 날짜 | 손익 |
|---|---|---|
| 매입·매출 계산서 | 계산서 작성일 | 공급가액 (부가세 뺀 금액) |
| 카드 사용 | **사용일자** | 금액 (부가세 공제 추정분은 뺀 금액) |
| 현금 경비 · 분류된 은행 줄 | 거래일 | 금액 |
| 급여 · 사업소득 | 지급일 | 지급액 |
| 4대보험 회사 부담 | 출금일 | 금액 |
| 국세 · 지방세 | 납부일 | **원천세 · 부가세는 비용 아님**, 그 밖의 세목은 비용 |
| 대출 | 상환일 | **이자만** 비용, 원금은 아님 |
| 카드대금 출금 · 내 계좌끼리 · 대표가 넣은 돈 | — | 손익에 넣지 않음 |

## 7. 「보낸 뒤 바뀜」

세무사에게 보낸 뒤 **보낸 파일에 들어가는 값이 바뀔 때만** 표시합니다.

| 바뀜으로 봄 | 아님 |
|---|---|
| 파일 올리기 · 지우기 · 중복 의심 선택 | 주거래처 표시 |
| 삐용 경비 다시 가져오기 (바뀐 것이 있을 때) | 「이번 달 없음」 · 「쓰지 않는 자료」 |
| 짝 확정 · 해제 · 수수료 · 일부 짝 | 세무 설정의 메일 · 별칭 |
| 분류 확정 · 고치기 | 화면 필터 · 정렬 |
| 거래처 이름 · 사업자번호 고치기 · 합치기 (모든 달에 나오므로 그 거래처가 있는 달 전부) | |
| 원천세 신고자료 다시 만들기 | |

표시 위치: 할 일 7단계 「진행 중 · 보낸 뒤 바뀐 자료 있음」, 전달 화면 상단 주황 띠, 이력 최신 줄 「보낸 뒤 바뀜」. 다시 보내면 풀립니다.

## 8. 원천세 반기납부

세무 설정에서 「반기납부」를 체크한 회사만.

| 반기 | 묶는 달 | [신고자료 만들기]가 켜지는 때 | 신고·납부 |
|---|---|---|---|
| 상반기 | 1~6월 지급분 | **6월 급여대장을 올리면** | 7월 10일 |
| 하반기 | 7~12월 지급분 | **12월 급여대장을 올리면** | 다음 해 1월 10일 |

- 작업할 달이 속한 반기를 보여 주고, 낼 세금은 그 반기 누적입니다
- 반기 마지막 달 급여대장 전에는 버튼이 꺼지고 「6월(12월) 급여대장을 올리면 [신고자료 만들기]가 켜집니다」
- 할 일 5단계는 「조회 · 6월(12월) 급여대장 뒤 만듦」
