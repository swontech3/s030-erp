## 1. 화면 ID 규칙

```
s030   010   0010   p1
 │      │     │      └─ 팝업 순번 (선택) — 모달·드로어·바텀시트 공통
 │      │     └─────── 화면 순번 4자리, 10단위
 │      └───────────── 업무 구분 3자리
 └──────────────────── 시스템 코드 (SwonBiz ERP)
```

- 파일명 예: `s0300200040.js` / `s0300200040p1.js`
- 팝업은 모달·드로어·바텀시트를 구분하지 않고 모두 `p{n}`
- 순번은 10단위 — 사이 삽입 시 `s0300200015` 형태로 여유 확보

### 업무 구분

| 코드 | 구분 | 비고 |
|---|---|---|
| 000 | 공통 | 인증, 셸, 대시보드, 설정 |
| 010 | 기준설정 | 건물·층·호실·회의실, 표양식 |
| 020 | 입주사관리 | 입주사, 계약, 청구, 멤버 |
| 030 | 세무 | 5차 |
| 040 | 법무 | 4차 |
| 050 | 공개 화면 | **인증 없이 접근** — 랜딩, 신청, 외부 예약, 현황판 |
| 060 | 공간운영 | 회의실 예약, 승인 큐 |

> **050의 기준은 업무가 아니라 인증 여부다.** 라우팅 미들웨어에서 050만 인증
> 제외로 처리할 수 있게 하기 위함. 회의실 예약이 050과 060으로 나뉘는 이유도
> 이것 — 외부 예약은 050, 로그인 예약은 060.

### 관련 스키마

- 테이블 접두어 `tb_s080_*` (SwonBiz ERP · 기존 앱과 공유, 제자리 확장)
- 참고: `s020_*` 삐용 / `s040_*` 법무·세무(계획)

## 4. 미해결 사항

**T7 온라인 신청 폼 (보류)** — 사업자 유무 분기가 계약 폼 필드 의미까지 바꿈.
아래 3건 결정 후 재개 (상세: `HANDOVER_T7_ErpApplyForm.md`)

1. 예비창업자를 계약 주체로 받는지
2. 법인 / 개인사업자를 나누는지
3. 개인(비사업자) 회원의 계약서 종류

**외부 회의실 예약 (보류)** — 추후 검토. 결제는 3차이므로 2차에서는
요청 → 승인 → 확정 흐름만

**기타**

- `BOOKING_QR_URL` 확정 및 인증 화면 `redirect` 파라미터 처리 확인
- ~~권한 관리 화면~~ — **해소.** ERP에 권한 관리 화면을 만들지 않는다. 권한 판정은
  삐용이 하고 ERP는 접근 가능 화면 목록을 받기만 한다 (`지시_ERP_로그인_권한관리.md` 2-1)
- 세션 만료 기본값이 삐용 JWT TTL과 일치하는지 확인
