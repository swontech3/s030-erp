# SwonBiz ERP — 디자인 인수인계

**1차 범위:** 디자인 기반 + 입주사·계약 관리 업무
**2차 범위:** 회의실 예약 · 회의실 현황판 → `room-booking/`
**대상:** ERP 개발팀
**개발 환경:** Next.js + Tailwind CSS
**제작 기준:** 고정 1440px (반응형은 업무 폴더의 `08-responsive.md`) · 현황판 1280×800
**최종 갱신:** 2026-09-27

---

## 프로젝트 개요

SwonBiz(스원비즈)는 강남 삼성동에서 12년째 소형 공유오피스를 운영하며,
입주사의 법무·세무 업무를 AI로 자동 처리하는 B2B SaaS입니다.
운영사는 `erp.swonbiz.com` 에서 입주사·계약·청구·세무를 관리하고,
입주사는 같은 시스템에서 자기 계약과 회의실을 씁니다.

**ERP 는 데스크톱 업무 도구입니다.** 실사용 환경이 1440px 이상이므로
시안도 고정 1440px 로 제작했습니다.

`tokens/` · `styles.css` · `assets/` 는 **원본 그대로**입니다.
정리·통합하지 않았으니 원본과 1:1 대조가 가능합니다.

### 컴포넌트 원본 소스

컴포넌트 원본은 디자인 시스템 프로젝트 루트의 `components/` 에 있으며 **별도로 전달**합니다.

```
core/       Button · IconButton · Icon · Card · Badge · Tag
forms/      Input · Select · Checkbox · Radio · Switch
navigation/ Tabs
feedback/   Dialog · Toast · Tooltip
```

> handoff/ 안에 복사해 두면 디자인 시스템 컴파일러가 같은 이름을 두 번 발견해
> `window.<NS>.Button` 등에서 충돌합니다. 그래서 한 폴더로 합치지 않았습니다.
> 개발 저장소에서는 `design/_ds/swonbiz/components/` 로 함께 두시면 됩니다.

각 컴포넌트는 `<Name>.jsx` + `<Name>.d.ts`(props 계약) + `<Name>.prompt.md`(용례) 로 구성됩니다.
`_ds_bundle.js` 는 컴파일 산출물이라 전달하지 않습니다 — 원본에서 React 로 옮기세요.

## 이관 시 주의사항

### 1. 색은 반드시 토큰으로
녹색 계열은 프로젝트 전체에서 **금지**입니다. 완료·성공·정상도 `--color-primary` 로 표현합니다.
`--color-success` 같은 토큰은 정의하지 않았으니, 빌드에 녹색 검사를 그대로 거셔도 됩니다.
오렌지는 로고 전용이고, 시안은 AI 표시와 현재 시각 마커 전용(화면의 5% 이내)입니다.

### 2. 템플릿의 리터럴 색값
마크업에 직접 박힌 색이 세 부류 있습니다.

| 부류 | 예 | 처리 |
|---|---|---|
| 의도된 리터럴 | 다크 그라디언트 시작값 `#131C33`, `rgba(79,70,229,.18)` | 그대로 두세요 — CSS 변수로 알파 조합이 불가능합니다 |
| 토큰화 권장 | 다크 패널의 `rgba(255,255,255,.06/.10/.14)` | 반복되므로 `--surface-inverse-raised` 같은 이름으로 올리면 좋습니다 |
| 토큰화 필요 | 키오스크의 `--k-booked` 등 4개 | 파일 로컬 변수로 두었습니다. `tokens/colors.css` 로 올릴지 판단해 주세요 |

### 3. 테이블은 `<table>` 이 아니라 CSS Grid
열 정렬 규칙이 `05-patterns.md#6` 에 있습니다. **minmax 하한 합계**를 반드시 확인하세요 —
하한은 하드 최소값이라 합이 사용 가능 폭을 넘으면 그대로 가로 스크롤이 생깁니다.

### 4. 헤더와 본문은 같은 스크롤 컨테이너에
따로 두면 본문에만 스크롤바가 생겨 열이 어긋납니다. 헤더를 `position:sticky; top:0` 으로 고정하세요.

### 5. 입력 중 리렌더 금지
금액 필드는 콤마 재삽입 때문에 커서 보정이 필요하고, 입력 중 행을 다시 그리면 포커스를 잃습니다.
`05-logic.md#5` 의 코드를 그대로 쓰세요.

### 6. 단일 소스 원칙
계약구분·회원구분처럼 여러 곳이 참조하는 값을 **DOM Select 에서 읽지 마세요.**
시안에서 반복해서 문제가 됐던 지점입니다.

### 7. 고정 1440px 제작
시안은 전부 1440px 고정 폭입니다. 축소 시 접힘 규칙은 `tenant-contract/08-responsive.md` 를 따르세요.
1차에서는 **xl(1280px 이상)만 정확히 맞추면 충분합니다** — ERP 는 데스크톱 업무 도구입니다.

### 8. 인라인 스타일이 아니라 토큰 기반 클래스로
시안(`.dc.html`)은 스트리밍 렌더링 제약 때문에 인라인 스타일로 작성돼 있습니다.
이관 시에는 Tailwind 유틸리티 또는 컴포넌트 클래스로 바꾸고,
**하드코딩 색값 대신 토큰명**을 쓰세요. 리터럴을 남겨야 하는 예외는 위 2번을 참고하세요.

### 9. 시안 데이터는 예시
브릿지랩 주식회사 · 노틸러스 · Room-1 · 최현수 등은 전부 예시값입니다.
단, **㈜에스원테크의 사업자 정보와 인감은 실제 값**입니다 (계약서에 출력됨).
