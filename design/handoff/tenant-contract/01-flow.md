# 업무 흐름 — 입주사·계약 관리

## 화면 구성

| 화면 | 파일 | 성격 |
|---|---|---|
| 입주사·계약 관리 | `erp-master-detail/ErpMasterDetail.dc.html` | 좌우 2단, 화면 전환 없음 |
| 계약 폼 | `erp-contract-form/ErpContractForm.dc.html` | 전체 페이지, 상태 5종 |

> 입주사 단일 목록형(`ErpTenants`)도 디자인되어 있으나 **1차 인계에서 제외**합니다.
> 마스터-디테일이 기능적 상위집합이고, 같은 데이터를 두 화면에서 관리하면
> 유지보수 부담이 커집니다.

---

## 흐름도

```
입주사·계약 관리 (ErpMasterDetail)
 │
 ├─ [신규 입주사 등록]  ─────────────→ 계약 폼 (mode: create, 전부 빈 값)
 │
 ├─ 좌측 입주사 카드 선택
 │   └→ 우측 계약 이력 갱신 (화면 전환 없음)
 │       │
 │       ├─ [신규 계약] ────────────→ 계약 폼 (mode: create, 회사 정보 자동 채움)
 │       │
 │       ├─ 계약 행 클릭 ───────────→ 계약 상세 모달 (720px)
 │       │   ├─ [닫기]
 │       │   ├─ [계약 상세] ────────→ 계약 폼 (mode: confirmed)
 │       │   └─ [재계약] ───────────→ 계약 폼 (mode: create, 이전 계약 값 복사)
 │       │
 │       └─ 행 액션 [재계약] ───────→ 계약 폼 (mode: create, 이전 계약 값 복사)
 │
 └─ 계약 폼 (ErpContractForm)
     ├─ [임시저장] ──────────────→ draft
     ├─ [계약확정] → 확인 모달 ──→ confirmed   (섹션 2 잠금)
     ├─ [계약취소] → 확인 모달 ──→ cancelled   (전 섹션 잠금)
     ├─ [종료]     → 확인 모달 ──→ terminated  (전 섹션 잠금)
     ├─ [계약서 출력] ───────────→ 미리보기 모달 (1000px) → 브라우저 인쇄
     └─ [이전] ─────────────────→ 목록으로
```

## 업무 순서

1. **신규 입주사가 들어올 때**
   `신규 입주사 등록` → 계약 폼에서 회사 정보 + 계약 항목 + 사용자 + 첨부 서류를 채움
   → 서류가 덜 갖춰졌으면 `임시저장`(draft), 갖춰졌으면 `계약확정`(confirmed)

2. **기존 입주사가 호실을 추가할 때**
   해당 입주사 선택 → `신규 계약` → 회사 정보는 자동으로 채워지고 계약 정보만 입력

   > 계약 조건(계약일자·기간·시작일·종료일·납부방법)이 기존 계약과 **하나라도 다르면 별도 계약**입니다.
   > 같으면 기존 계약에 항목을 추가하세요.

3. **만기가 다가올 때**
   계약 행 액션 `재계약` → 이전 계약 값이 전부 복사된 상태로 열림 → 계약기간 3필드만 확인

4. **중도 해지**
   계약 폼(confirmed) → `종료` → 종료일·사유 입력 → terminated
   해당 호실이 예약 가능 상태로 돌아갑니다.

## 진입 시 prefill 규칙

| 진입점 | mode | 회사 정보 | 계약 항목 | 계약 조건 |
|---|---|---|---|---|
| 신규 입주사 등록 | create | 빈 값 | 1행 빈 값 | 빈 값 |
| 신규 계약 | create | 선택된 입주사 값 (읽기 전용 표시 권장) | 1행 빈 값 | 빈 값 |
| 재계약 | create | 선택된 입주사 값 | 이전 계약 항목 전체 복사 | 계약기간·시작일·종료일만 비움 |
| 계약 상세 | confirmed | 저장값 | 저장값 (잠금) | 저장값 (잠금) |

> 재계약의 시작일 기본값은 **이전 계약 종료일의 다음 날**입니다.
