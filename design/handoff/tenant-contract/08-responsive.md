# 반응형 가이드

시안은 **고정 1440px** 로 제작했습니다. 아래는 축소 시 접힘 규칙입니다.
모든 값은 Tailwind 기본 브레이크포인트 기준입니다.

```
sm 640  /  md 768  /  lg 1024  /  xl 1280
```

---

## 입주사·계약 관리 (마스터-디테일)

| 폭 | 레이아웃 |
|---|---|
| xl↑ | 좌 420px 고정 + 우 나머지, 2열 유지 |
| lg | 좌 **360px** 로 축소. 카드 2행 구조 유지, 2행 폰트 13px |
| md | 좌 **320px**. 상태 칩을 2행으로 접거나 가로 스크롤 허용 |
| sm | **목록만** 표시. 입주사 선택 시 상세를 페이지 이동으로 전환 |

우측 계약 테이블은 `minmax` 기반이라 자동으로 줄어듭니다.
md 이하에서 하한 합계가 넘으면 아래 순서로 열을 숨깁니다.

```
1순위  기간        (계약일자에 개월 수를 병기)
2순위  플랜·호실    (행 클릭 후 상세 모달에서 확인)
3순위  상태 뱃지    (만기 임박 텍스트만 남김)
```

액션 열은 마지막까지 유지합니다 — 재계약이 주요 동선입니다.

---

## 계약 폼

### 필드 그리드

| 폭 | 열 수 |
|---|---|
| xl↑ | 4열 |
| lg | 3열 |
| md | 2열 |
| sm | 1열 |

`span 2` / `span 4` 필드는 열 수에 맞춰 조정합니다.

```css
grid-template-columns: repeat(1, minmax(0,1fr));
@media (min-width:768px)  { grid-template-columns: repeat(2, minmax(0,1fr)); }
@media (min-width:1024px) { grid-template-columns: repeat(3, minmax(0,1fr)); }
@media (min-width:1280px) { grid-template-columns: repeat(4, minmax(0,1fr)); }
```

### 계약 항목 테이블 (10열)

**md 이하에서는 카드 형태로 전환합니다.** 10열을 유지하면 어느 폭에서도 읽을 수 없습니다.

```
카드 1장 = 항목 1개
 ┌────────────────────────────────┐
 │ No.1            [삭제]          │
 │ 계약구분 Select  호실 Select     │   2열
 │ ─────────────────────────────  │
 │ 월회비   450,000 (ReadOnly)     │   라벨-값 2열
 │ 예치금   450,000                │
 │ 월이용료 400,000  -50,000       │
 │ 계산서발행 [체크]                │
 │ ─────────────────────────────  │
 │ 부가세액  40,000                │
 │ 납부액   440,000 (weight 700)   │
 └────────────────────────────────┘
```

합계 블록은 sm 에서 5등분 → 2열 그리드로 접습니다 (월납부액은 span 2 로 강조 유지).

### 입주자 사용자 테이블 (8열)

md 이하에서 같은 방식으로 카드 전환.
선택 체크박스는 카드 우상단, 대표자 뱃지는 이름 옆에 pill 로.

### 페이지 헤더

md 이하에서 액션 버튼이 넘치면 — 주요 버튼(계약확정·저장) 2개만 남기고
나머지는 `more-horizontal` 드롭다운으로 묶습니다.

## 계약서 미리보기

**A4 폭 794px 을 유지하고 가로 스크롤을 허용합니다.**
축소하면 인쇄물과 화면이 달라져 검토 목적을 잃습니다.

```
모달 폭  min(1000px, 100vw - 32px)
본문     overflow: auto  (가로·세로 모두)
문서     width: 794px  — 축소하지 않음
```

sm 에서는 모달 대신 전체 화면으로 띄우고 상단에 닫기 바를 둡니다.

## ERP 셸

| 폭 | 사이드바 |
|---|---|
| xl↑ | 248px 펼침 (localStorage 값 우선) |
| lg | 64px 접힘 기본 |
| md 이하 | 오버레이 드로어 — 햄버거 버튼으로 열고 백드롭 클릭으로 닫힘 |

md 이하에서 토글 버튼(경계선 배치)은 숨기고 헤더 좌측 햄버거로 대체합니다.

---

## 우선순위

1차 이관에서는 **xl(1280px 이상) 만 정확히 맞추면 됩니다.**
ERP 는 데스크톱 업무 도구이고, 실사용 환경이 1440px 이상입니다.
lg 이하는 "깨지지 않는 수준"이면 충분하며, sm 대응은 2차 이후로 미뤄도 됩니다.
