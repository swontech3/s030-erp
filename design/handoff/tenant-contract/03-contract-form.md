# 화면 2 · 계약 폼

파일: `erp-contract-form/ErpContractForm.dc.html`
계약 등록·수정·상세를 하나의 페이지로 처리합니다. 필드가 30개를 넘어 모달이 아닙니다.

> 섹션 1·3·4 는 비로그인 온라인 신청 폼에 그대로 재사용합니다.
> 각 섹션이 독립적으로 분리 가능해야 합니다. 섹션 5(계약서)는 신청 폼에서 제외합니다.


### 사업자번호 확인

인풋 우측에 [확인] 버튼, 그 우측 8px 에 결과 아이콘 20px + hover 툴팁.
실패일 때만 인풋 하단 4px 에 짧은 문구를 덧붙입니다.

| 결과 | 아이콘 | 색 | 툴팁 | 하단 문구 |
|---|---|---|---|---|
| 성공 | `circle-check` | `--color-primary` | 등록 가능한 사업자입니다 | 없음 |
| 중복 | `circle-alert` | `--color-danger` | 이미 등록된 사업자번호입니다 | 이미 등록된 번호 |
| 무효 | `circle-alert` | `--color-warning` | 국세청에 등록되지 않은 번호입니다 | 국세청 미등록 |

placeholder: `000-00-00000 (사업자등록 전이면 비워두세요)`
중복 여부와 국세청 유효성을 한 번에 검사합니다. **국세청 API 실연동 여부 TBD** — 미연동 시 형식 검증만.

## 섹션 2 · 계약정보

계약 1건 = 계약 항목 N개 + 계약 조건 1세트.

섹션 헤더 우측에 건물 Select 160px + 층 Select 120px (높이 36px). confirmed 이후 숨김.

### 2-1. 계약 항목 테이블

소제목 행 — "계약 항목" 14px/700 + 건수 12px `--text-muted`, 우측 [항목 추가] ghost 32px

```css
grid-template-columns:
  40px                    /* No — 중앙 */
  minmax(120px, .8fr)     /* 계약구분 — Select */
  minmax(130px, .9fr)     /* 호실 — Select */
  minmax(110px, .75fr)    /* 월회비 — ReadOnly, 우측 */
  minmax(110px, .75fr)    /* 예치금 — 입력, 우측 */
  minmax(110px, .75fr)    /* 월이용료 — 입력, 우측 */
  70px                    /* 계산서발행 — Checkbox 중앙 */
  minmax(100px, .7fr)     /* 부가세액 — ReadOnly, 우측 */
  minmax(110px, .8fr)     /* 납부액 — ReadOnly, 우측, weight 700 */
  48px;                   /* 삭제 — confirmed 이후 트랙 제거 */
align-items: center;
```

행 상하 패딩 10px, 셀 좌우 패딩 6px, 입력 높이 38px, 폰트 14px.

| 열 | 동작 |
|---|---|
| 계약구분 | 비상주 / 고정석 / 1인실 / 2인실 / 팀오피스 — **같은 구분 중복 선택 가능** |
| 호실 | 모든 계약구분에서 활성 (비상주 포함), **중복 선택 제한 없음**. 선택 시 그 행의 월회비·예치금·월이용료 자동 입력 |
| 월이용료 | 월회비와 다르면 아래 12px `--color-primary` 로 차액 표시 ("-50,000") |
| 계산서발행 | 기본 체크. 그 행의 부가세액을 좌우 |
| 삭제 | `trash-2` 30px, 행이 1개면 비활성 |

기본 1행, **최대 10행**. 도달 시 [항목 추가] 비활성 + 툴팁 "최대 10개까지 등록 가능".

### 2-2. 금액 합계 블록 (상단 12px)

```
배경 --surface-alt, radius --radius-md, 패딩 16px 20px 16px 24px
좌측 3px --color-primary 세로 바
가로 5등분 — 예치금 / 월회비 / 월이용료 / 부가세액 / 월납부액
  라벨 12px --text-muted
  값 16px/700 --text-heading, tabular-nums (월납부액만 --color-primary)
월회비 합계 ≠ 월이용료 합계이면 월이용료 아래 12px --color-primary
  "기준가 대비 -110,000원 (11.1% 할인)"
```

### 2-3. 계약 조건 블록 (상단 18px, 4열 그리드)

| 행 | 필드 |
|---|---|
| 1 | 계약호실 (ReadOnly + 조회 아이콘 40px) / 납부방법 * / 첫달납부액 (강조) / 접근경로 |
| 2 | 계약일자 * / 기간(월) * / 시작일 * / 종료일 (ReadOnly) |
| 3 | 특기사항 (span 4, Textarea 2행) |

- **계약호실** — 국세청 신고용 대표 호실. 계약당 1개. 조회 팝업은 미구현
- **첫달납부액** — 배경 `--color-accent-bg`, 보더 `1px --color-primary`, 값 700 `--color-primary`
  일시불이면 아래 12px `--text-muted` 산식 "예치금 + 6개월 × 968,000원"
- **특기사항** — 위에 12px `--text-muted` "할인이 있으면 첫 줄에 자동 기재됩니다"

> 예치금·계산서발행은 **항목별로만** 관리합니다. 계약 조건 블록에 두지 마세요.

## 섹션 3 · 입주자 사용자 정보

계약 항목과 **연동하지 않습니다.** 사용자가 직접 행을 추가·삭제합니다.

섹션 헤더 우측 — "3명 등록" 14px `--text-muted`

```css
grid-template-columns:
  48px                    /* 선택 체크박스 */
  48px                    /* No */
  minmax(150px, .9fr)     /* 성명 */
  minmax(180px, 1fr)      /* 연락처 */
  minmax(300px, 1.7fr)    /* 이메일 — 아이디 + "@" + 도메인 Select 140px */
  80px                    /* 대표자 */
  minmax(160px, 1fr)      /* 비고 */
  56px;                   /* 삭제 */
```
행 상하 패딩 10px, 셀 좌우 패딩 10px, 입력 높이 40px.

### 1행 — 자동 채움 + ReadOnly

성명·연락처·이메일이 섹션 1의 대표자 값을 **실시간 미러링**합니다(비고만 입력 가능).
선택 체크박스 체크 고정(해제 불가), 대표자 체크 고정, 삭제 비활성.

### 2행 이후

전 항목 입력 가능, 삭제 가능, 기본 체크 상태. 최대 20행.
연락처는 섹션 1과 동일한 마스크를 적용합니다.

### 선택 체크박스

- 헤더에 전체 선택 (1행 제외)
- 미체크 행: 배경 `--surface-alt`, 입력 `opacity:.5`, 대표자 체크박스 비활성
- **입력값은 유지**하고 저장 시에만 제외합니다

### 대표자 체크박스

1명만 선택 — 라디오처럼 동작합니다(체크 시 나머지 해제).

### 하단 [사용자 추가]

점선 보더 `1px --border`, radius `--radius-md`, 높이 44px, 전체 폭
`plus` 16px + "사용자 추가" 14px `--text-muted`, hover 시 보더·텍스트 `--color-primary`
20행 도달 시 비활성 + 툴팁.

> 행을 다시 그릴 때 2행 이후 입력값을 캐시했다가 복원하세요. 그러지 않으면
> 섹션 1 대표자를 수정할 때마다 사용자가 입력한 값이 사라집니다.

## 단일 소스 원칙

계약구분·회원구분처럼 **여러 곳이 참조하는 값은 DOM Select 에서 읽지 마세요.**
state 에 보관하고 getter 하나로 노출합니다.

```js
get memberType() {
  if (this.state.memberType !== undefined) return this.state.memberType;
  if (this.props.memberType) return this.props.memberType;
  return this.mode === "create" ? "프리랜서" : DEMO.memberType;
}
```

seeding 되지 않은 렌더 패스에서 Select 가 첫 옵션에 머물러 있으면
DOM 을 읽는 로직이 잘못된 값으로 동작합니다.
