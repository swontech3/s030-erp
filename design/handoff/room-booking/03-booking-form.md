# 예약 등록 · 수정 · 상세 모달

**한 모달입니다.** 등록·수정·상세는 같은 마크업을 `mode` 로 분기합니다. 필드 구성도 같습니다.

폭 640px, 최대 높이 `100vh − 48px`, 본문 스크롤. 767 이하는 전체 화면 (`08-responsive.md#4`).

---

## 1. 여는 경로와 초기값

| 경로 | mode | 날짜·시간 | 회의실 |
|---|---|---|---|
| 빈 칸 드래그 (마우스) | create | 드래그 범위. 최소 이용시간보다 짧으면 **시작 기준으로 최소까지 늘림** | 툴바 회의실 |
| 빈 칸 탭 (터치) · 한 칸 클릭 | create | 그 칸 시작 + 최소 이용시간 | 툴바 회의실 |
| 예약 추가 버튼 | create | 보고 있는 날(주간: 그 주에 오늘이 있으면 오늘, 없으면 월요일 / 767 이하: 선택된 날)의 **첫 빈 칸** + 최소 이용시간 | 툴바 회의실 |
| 예약 블록 클릭 | edit 또는 view | 저장값 | 저장값 |

> 최소를 채우다 다음 예약과 겹치면 그대로 열고 충돌 오류를 보여줍니다. 몰래 줄이지 않습니다.

### 드래그 규칙 (마우스, 템플릿 로직 유지)

- 같은 날 열 안에서만. 다른 열로 나가면 무시
- 기존 예약·차단 칸을 만나면 **그 직전까지** — 가로질러 선택되지 않음
- 최대 이용시간(칸 수)에서 멈추고, 고스트 두 번째 줄에 「최대 4시간」
- 고스트: 1px dashed `--color-primary`, 배경 `rgba(79,70,229,.10)`, 「14:00–15:30 (1시간 30분)」 12px/700
- 놓으면 모달이 열림. 고스트는 즉시 제거

터치는 `08-responsive.md#3`.

## 2. mode 3종

| | create | edit | view |
|---|---|---|---|
| 제목 | 회의실 예약 | 예약 수정 | 예약 상세 |
| 상태 뱃지 (제목 옆) | 없음 | 확정 | 종료 · 취소 |
| 필드 | 입력 | 입력 | **전부 disabled** |
| 좌측 버튼 | — | 예약 취소 (danger ghost) | — |
| 우측 버튼 | 취소 · **예약하기** | 취소 · **저장** | 닫기 |
| 하단 메타 | — | 「등록 9월 29일 14:02 · 김도현」 12px `--text-caption` | 같음 |

### 어떤 블록이 어떤 mode 로 열리나

```
statusOf(b) !== "confirmed"                          → view   (종료·취소는 누구도 못 고침)
운영자                                               → edit   (진행 중·지난 확정 예약도 수정 가능)
입주사 · 우리 조직 · 시작 전                          → edit
입주사 · 우리 조직 · 진행 중                          → view
입주사 · 타사                                        → 열리지 않음
```

## 3. 필드

섹션 제목은 16px/700 + 좌측 3px×16px `--color-primary` 바 (템플릿 그대로). 필드 라벨 12px `--text-muted`.
그리드 6열, column-gap 12, row-gap 14.

### 섹션 1 · 예약 정보

| 필드 | 폭 | 입력 | 수정 가능 | 규칙 |
|---|---|---|---|---|
| 회의실 | 6 | Select 「회의실 A (4~5인)」 | ○ | 바꾸면 시작·종료 옵션을 그 회의실 운영시간으로 다시 만들고, 기존 시간을 운영시간 안으로 맞춤(길이 유지). 인원이 정원을 넘으면 정원으로 |
| 날짜 | 2 | `type=date` | ○ | 입주사 `min=오늘` `max=오늘+27일` |
| 시작 | 2 | Select 30분 간격 `open` ~ `close−30` | ○ | 바꾸면 **길이를 유지한 채** 종료를 같이 이동 (길이가 최소보다 짧으면 최소) |
| 종료 | 2 | Select 30분 간격 `open+30` ~ `close` | ○ | |

필드 아래 (한 줄씩):

```
⚠ 이미 예약된 시간과 겹칩니다                      12px --color-danger (오류일 때만)
회의실 A · 운영 09:00 – 22:00 · 1회 30분 ~ 4시간    12px --text-muted (항상)
9월 30일 우리 조직 예약 1시간 · 1시간 더 예약할 수 있습니다   12px --text-muted (입주사만)
```

시간 오류가 있으면 시작·종료 테두리 `--color-danger` + **제출 버튼 disabled**. 메시지 목록은 `05-logic.md#4`.

### 섹션 2 · 예약 내용

| 필드 | 입력 | 필수 | 규칙 |
|---|---|---|---|
| 회의 제목 | Input maxlength 40, placeholder 「주간 회의」 | ○ | 제출 시 비어 있으면 「회의 제목을 입력해 주세요」 + 포커스. 입력하면 오류 즉시 해제 |
| 참석 인원 | 스테퍼 44px (− 값 +) + 「최대 5명」 | | 1 ~ 회의실 정원. 끝에서 버튼 disabled. 기본 min(4, 정원) |
| 메모 | Textarea 2행, maxlength 200 | | |

### 섹션 3 · 예약자 정보

| 상황 | 표시 |
|---|---|
| 입주사 create | 잠금 블록: 조직명 · 등록자 · 연락처 (로그인 정보). 우측 안내 「로그인 정보로 자동 입력됩니다」 |
| 운영자 create | **예약 조직 Select** (입주사 목록 + 「에스원테크 (운영사)」, 기본 운영사) + 잠금 블록. 안내 「등록자는 로그인한 운영자로 기록됩니다」 |
| edit · view | 잠금 블록: 조직명 · 예약자 · 연락처 (저장값). 안내 「등록 후에는 바꿀 수 없습니다」 |

잠금 블록: `--surface-alt`, 좌측 3px `--color-primary`, 라벨 12px / 값 16px (조직명 700).

## 4. 예약 수정 — 무엇까지 고칠 수 있나

| 항목 | 수정 | 이유 |
|---|---|---|
| 회의실 · 날짜 · 시작 · 종료 | ○ | 가장 흔한 변경. **모든 규칙을 등록과 똑같이 다시 검사** — 단 자기 자신은 충돌·하루 2시간 계산에서 제외 |
| 제목 · 인원 · 메모 | ○ | |
| 예약 조직 · 예약자 | × | 조직을 바꾸는 건 사실상 다른 예약입니다. 취소 후 새로 등록 |
| 상태 | 버튼으로만 | 「예약 취소」 → 확인 → `cancelled` |

- 입주사는 **시작 전**까지만 수정·취소. 시작 시각이 지나면 상세(view)로 열립니다
- 운영자는 진행 중인 예약도 수정할 수 있습니다 (연장·조기 종료 기록용)
- 저장 시 서버가 다시 검증합니다. 그 사이 다른 예약이 들어왔으면 `05-logic.md#6`

## 5. 예약 취소 확인 모달

`tenant-contract/04-status.md` 확인 모달 규격(480px)을 그대로 씁니다.

```
아이콘  circle-x 24px --color-danger, 배경 --color-danger-bg (56px 원)
제목    "예약을 취소하시겠습니까?"
설명    "취소한 시간은 바로 다른 조직이 예약할 수 있습니다.
         이 작업은 되돌릴 수 없습니다."
요약    회의실 A · 9월 30일 16:00–17:00    (--surface-alt 박스)
버튼    [돌아가기] ghost / [예약 취소] danger (각 50%, 44px)
```

확인 → 두 모달 닫힘 → 그리드에서 블록 제거 → 토스트.

## 6. 피드백

| 결과 | 토스트 (하단 중앙, 2.4초) |
|---|---|
| 등록 | 예약했습니다 |
| 수정 | 예약을 변경했습니다 |
| 취소 | 예약을 취소했습니다 |

저장 후 그리드는 **저장한 회의실 · 날짜로 이동**합니다 (모달에서 회의실을 바꿨을 수 있으므로).

닫기: X · 취소 버튼 · 오버레이 클릭 · Esc. 입력 중이어도 확인 없이 닫습니다 (필드가 적어 재입력 부담이 작음).
