# 화면 폭별 구성

회의실 예약은 입주사가 **휴대폰으로도 쓰는 화면**입니다 (현황판 QR 진입). 입주사·계약과 달리 767 이하도 1차 범위입니다.

시안은 확인 컨트롤 바의 「폭」으로 프레임 폭을 바꿔 확인합니다. 시안은 프레임에 `is-xl / is-md / is-sm` 클래스를 붙이지만,
**실제 구현은 같은 경계의 미디어 쿼리**로 하시면 됩니다.

```
xl  1280 이상      md  768 ~ 1279      sm  767 이하
```

---

## 1. 요약

| | 1280 이상 | 768 ~ 1279 | 767 이하 |
|---|---|---|---|
| 사이드바 | 248px 펼침 | 64px 아이콘 | 숨김 · 햄버거 → 오버레이 드로어 |
| 헤더 | 64px, 권한 안내 표시 | 64px, 권한 안내 숨김 | 56px, 계정은 아바타만 |
| 툴바 | 한 줄 | 필요하면 두 줄로 wrap | 1줄: 이동·기간 / 2줄: 회의실 Select 전체 폭 |
| 보기 | 주간 · 월간(운영자) | 주간 · 월간(운영자) | **하루** — 월간 없음 |
| 그리드 열 | 72px + 7일 | 56px + 7일 | 56px + 1일 |
| 날짜 이동 | ‹ › = 1주 | ‹ › = 1주 | ‹ › = 1일 + 날짜 스트립 |
| 예약 추가 | 툴바 버튼 | 툴바 버튼 | 하단 고정 버튼 48px |


- 날짜 스트립: 기준 날짜가 속한 주의 7일. 탭하면 그 날로. 오늘은 숫자 `--color-primary`, 선택은 흰 배경 + 1px `--color-primary` 테두리
- 입주사 4주 밖 날짜는 opacity .4 (탭은 가능 — 칸이 모두 차단되어 보임)
- ‹ › 는 하루씩. 주가 넘어가면 스트립도 넘어감
- 요일 헤더 행은 숨깁니다 (스트립이 대신함)
- 블록은 1칸짜리도 제목을 보여줍니다 (열이 넓음). 제목 14px, 시간 12px
- 패널 하단 여백 84px — 하단 버튼에 가리지 않게

## 3. 드래그 대신 탭 — 터치 입력

터치에서 드래그는 **스크롤과 충돌**합니다. 세로로 긴 그리드를 스크롤하려는 손가락이 예약을 만들면 안 됩니다.
그래서 터치(모든 폭)에서는 드래그 선택을 하지 않습니다.

| 입력 | 동작 |
|---|---|
| 마우스 누른 채 끌기 | 드래그 선택 (`05-logic.md#5`) |
| 마우스 클릭 한 번 | 그 칸 + 최소 이용시간으로 모달 |
| 터치 탭 | 그 칸 + 최소 이용시간으로 모달 — 길이는 모달의 종료 Select 로 조정 |
| 터치 끌기 | 스크롤. 선택하지 않음 |

### 구현

`pointerType` 으로 분기합니다. 터치는 `pointerdown` 에서 아무것도 그리지 않고, **같은 칸에서 `pointerup`** 이 나야 탭으로 봅니다.
스크롤이 시작되면 브라우저가 `pointercancel` 을 보내므로 선택이 자연히 취소됩니다.

```js
body.addEventListener("pointerdown", (e) => {
  const c = e.target.closest(".cell");
  if (!c || c.classList.contains("is-blocked") || e.button > 0) return;
  drag = { date: c.dataset.date, from: +c.dataset.slot, lo: +c.dataset.slot, hi: +c.dataset.slot,
           mouse: e.pointerType === "mouse" };
  if (drag.mouse) { e.preventDefault(); paintGhost(); }          // 텍스트 선택 방지
});
body.addEventListener("pointerover", (e) => { if (drag?.mouse) extend(drag, slotUnder(e)); });
document.addEventListener("pointercancel", () => { drag = null; hideGhost(); });   // 터치 스크롤 시작
document.addEventListener("pointerup", (e) => {
  if (!drag) return;
  const d = drag; drag = null; hideGhost();
  if (!d.mouse) {                                                // 탭 판정
    const c = document.elementFromPoint(e.clientX, e.clientY)?.closest(".cell");
    if (!c || c.dataset.date !== d.date || +c.dataset.slot !== d.from) return;
  }
  openCreate(d.date, d.lo, d.hi);
});
```

그리드 스크롤 컨테이너에 `touch-action` 을 따로 걸지 마세요 (기본 `auto` 여야 스크롤 → `pointercancel` 이 동작합니다).
블록의 `pointerdown` 은 `stopPropagation` — 블록을 누르면 선택이 아니라 열기입니다.

> 롱프레스 후 드래그 같은 제스처는 넣지 않았습니다. 발견되지 않고, 한 번의 탭 + 종료 Select 가 더 빠릅니다.

## 4. 모달 — 767 이하

- 전체 화면 (`inset:0`, radius 0). 헤더·푸터 패딩 16px
- 필드 그리드: 회의실·날짜 전체 폭 / 시작·종료 반씩 / 나머지 전체 폭
- 입력 글자 16px — iOS 자동 확대 방지
- 푸터 버튼은 같은 폭으로 늘림. 수정 모드는 [예약 취소] [취소] [저장] 3개
- 등록으로 열려도 제목에 자동 포커스하지 않습니다 (키보드가 시간 필드를 가림)
- 예약 취소 확인 모달은 그대로 480px 중앙 (좌우 16px 여백)

---

## 5. 768 ~ 1279

- 7일 유지. 1024 에서 열 폭 ≈ 115px — 시간·제목은 들어가고 「운영사」 뱃지는 겹치므로 숨김
- 툴바가 넘치면 우측 그룹이 다음 줄로 (flex-wrap). 순서 유지
- 태블릿(터치)에서도 7일 그리드 — 선택은 탭 (3번)

---

## 우선순위

1. **1280 이상** — 운영자 주 사용 환경
2. **767 이하** — 입주사 휴대폰, QR 진입. 탭 선택과 전체 화면 모달까지
3. 768 ~ 1279 — 깨지지 않는 수준이면 충분
