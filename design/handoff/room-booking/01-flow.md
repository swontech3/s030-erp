## 흐름도

```
회의실 예약 (s0300600010)
 │
 ├─ 툴바
 │   ├─ [‹] [오늘] [›]        주간 = 한 주 · 월간 = 한 달 · 767 이하 = 하루
 │   ├─ 회의실 Select          그리드·규칙 문구·운영시간 행이 그 회의실 설정으로 바뀜
 │   ├─ [월간 | 주간]          운영자 · 768 이상에서만 표시
 │   └─ [+ 예약 추가] ────────→ 등록 모달 (보고 있는 날의 첫 빈 칸, 최소 이용시간)
 │
 ├─ 주간 그리드
 │   ├─ 빈 칸 드래그 (마우스) ──→ 등록 모달 (선택 범위)
 │   ├─ 빈 칸 탭 (터치) ───────→ 등록 모달 (그 칸 + 최소 이용시간)
 │   ├─ 예약 블록 클릭
 │   │   ├─ 수정 가능 ─────────→ 수정 모달 ── [저장] / [예약 취소] → 확인 모달 → cancelled
 │   │   ├─ 볼 수 있음 ────────→ 상세 모달 (읽기 전용) ── [닫기]
 │   │   └─ 「예약됨」(타사) ──→ 반응 없음
 │   └─ 차단된 칸 ─────────────→ 반응 없음 (title 로 사유)
 │
 └─ 월간 (운영자)
     └─ 날짜 클릭 ─────────────→ 그 날짜가 속한 주의 주간 보기
```

## 업무 순서

1. **입주사가 직접 예약** — 주간에서 빈 시간을 끌어 선택 → 제목 입력 → 예약하기 → 즉시 확정
2. **입주사가 전화로 요청** — 운영자가 예약 추가 → 예약 조직에서 해당 입주사 선택 → 예약하기.
   이 경우 입주사 제한(4주·2시간·지난 시각)은 **적용되지 않습니다** (운영자 등록이므로)
3. **시간 변경** — 자기 예약 블록 클릭 → 수정 모달에서 시간·회의실·내용 변경 → 저장
4. **취소** — 수정 모달 → 예약 취소 → 확인 → 그 시간이 즉시 비어 다른 조직이 예약 가능
5. **현장 예약** — 현황판 QR → 휴대폰에서 이 화면이 그 회의실 · 오늘로 열림 (`06-kiosk.md#6`)

## 진입 파라미터

| 파라미터 | 값 | 기본 | 비고 |
|---|---|---|---|
| `room` | 회의실 ID | 지점의 첫 회의실 | 없는 ID 면 기본값 |
| `date` | `YYYY-MM-DD` | 오늘 | 입주사가 4주 밖 날짜로 들어오면 오늘로 |
| `view` | `week` · `month` | `week` | 입주사 · 767 이하에서는 무조건 `week` (서버도 차단) |
| `src` | `kiosk` | — | 현황판 QR 진입 표시. 동작 차이는 `06-kiosk.md#6` |

진입 시 주간 그리드는 **현재 시각 1시간 전**이 맨 위에 오도록 스크롤합니다.
