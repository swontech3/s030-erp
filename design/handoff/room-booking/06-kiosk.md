# 회의실 현황판 (s0300500060)

회의실 문 옆 벽면 태블릿. **로그인 없음 · 표시 전용 · 24시간 켜 둠.**
원본 `erp-booking-kiosk/ErpBookingKiosk.dc.html`, 시안 `prototypes/s0300500060.html`.

기준 **1280×800 가로**. 기종이 정해지면 알려 주세요 — 그때 `7번` 크기 규칙만 확인하면 됩니다.

## 2. 표시 원칙

- **제목 · 조직 · 인원은 어디에도 없습니다.** 시간과 「예약됨」만. 복도에서 누구나 보는 화면입니다
- 서버 응답부터 시간만 담으세요 (`07-data-model.md` 의 `masked` 형태와 같음)
- 터치로 바뀌는 상태는 없습니다. 예외는 우하단 72px 영역 3회 탭 → 개발 정보(해상도·마지막 갱신) 5초
- 시안(`--k-now`)은 현재 시각 마커에만 씁니다 — 화면 유일한 액센트

## 3. 배너 — 상태 문구

배너 배경 하나로 원거리에서 판단되게 합니다. **사용 중만 인디고**, 나머지는 `--surface-alt` + 1px `--border`.

| 상황 | 조건 | 메인 (36px/800) | 보조 (24px) |
|---|---|---|---|
| 사용 중 | 시작 ≤ 현재 < 종료 | 사용 중 · 14:00까지 | 다음 예약 16:00 / 이후 예약 없음 |
| 사용 중 · 연속 | 종료 시각에 바로 다음 예약 | 사용 중 · 17:00까지 | **이어서 예약 17:00–18:00** |
| 비어 있음 | 다음 예약 있음 | 비어 있음 · 16:00까지 | 다음 예약 16:00–17:00 |
| 비어 있음 | 오늘 남은 예약 없음 | 비어 있음 | 오늘 남은 예약 없음 |
| 운영 시작 전 | 현재 < open | 운영 시작 전 | 09:00부터 · 첫 예약 11:00 |
| 운영 종료 | 현재 ≥ close | 운영 종료 | 내일 09:00부터 |
| 현황 확인 불가 | 30분 이상 끊김 | 현황을 확인할 수 없습니다 | 연결되면 자동으로 갱신됩니다 |

「비어 있음 · 16:00까지」 — 지나가다 들어가려는 사람에게 필요한 건 **언제까지 비어 있는지**입니다.
「내일 09:00」은 다음 운영일의 그 회의실 `openMinute` 입니다 (휴무일 처리는 TBD).

## 4. 타임라인

### 행 나누기 — 회의실 운영시간 기준

운영시간이 회의실마다 다르므로 템플릿의 「주간 09–18 / 야간 18–22」 고정 2행을 규칙으로 바꿨습니다.

```
한 행 최대 18슬롯 (9시간)
총 슬롯 ≤ 18   → 1행, 전체 폭               예: C 09–18
총 슬롯 > 18   → 18슬롯씩 나눠 2행           예: A 09–22 → 09–18 / 18–22
                 짧은 행은 폭을 (슬롯 수 / 18) 로 줄여 두 행의 30분 폭을 같게
```

- 좌측 라벨 72px: 「09–18」 18px `--text-muted` (템플릿의 「주간/야간」 대신 — 회의실마다 경계가 다르므로)
- 1행일 때 트랙 높이는 최대 210px, 세로 가운데 정렬
- 24시간(48슬롯) 회의실은 3행이 됩니다. 실제로 있으면 알려 주세요

### 트랙

| 요소 | 규격 |
|---|---|
| 트랙 | `--k-empty` #EEF0F4, radius 8px |
| 30분 경계 | 정시 1px 실선 `--border`, 30분 1px 점선 |
| 예약 막대 | `--k-booked` #818CF8, 좌측 3px `--k-booked-bar` #4F46E5, radius 8px. **텍스트 없음** |
| 현재 시각 | 3px `--k-now` 세로선 + 눈금 줄에 14×9 역삼각형 |
| 눈금 | 정시마다 「09」 20px `--text-muted`. 지난 시각은 opacity .3. 첫 눈금 왼쪽 정렬, 마지막 오른쪽 정렬, 나머지 가운데 |

예약 막대는 연속 예약이어도 합치지 않습니다 — 좌측 진한 선으로 경계가 보입니다.

## 6. QR — 여는 주소 ★ 결정

```
https://erp.swonbiz.com/booking?room={roomId}&src=kiosk
```

- 경로 `/booking` 은 **회의실 예약 화면(s0300600010)** 입니다. 라우터 경로명이 다르면 경로만 바꾸고 **파라미터 두 개는 유지**해 주세요
- `room` — `Room.id` (이름이 아니라 바뀌지 않는 ID)
- `src=kiosk` — 유입 집계용. 화면 동작에는 영향 없음
- **날짜를 넣지 않습니다.** 예약 화면 기본값이 오늘이므로 QR 이 하루 종일(그리고 영구히) 같습니다 → 실물 스티커로 백업 부착 가능
- 서버에서 한 번 생성해 이미지로 두면 됩니다. 현황판이 매번 만들 필요 없음

### 스캔 후

```
로그인 세션 있음 → 회의실 예약 · 그 회의실 · 오늘 · (휴대폰) 하루 보기, 현재 시각으로 스크롤
로그인 세션 없음 → 로그인 → 같은 주소로 복귀
```

모달을 자동으로 열지 않습니다. 빈 시간을 먼저 봐야 고를 수 있습니다.
입주사 제한(지난 시각·4주·하루 2시간)은 일반 예약과 똑같이 적용됩니다.

> 공용 화면에서 조직을 고르게 하지 않은 이유 — 오선택·사칭이 다른 조직의 하루 2시간을 소진시킵니다. 본인 휴대폰의 로그인 세션이 조직을 확정합니다.

## 7. 현황판 접속 · 갱신

### 접속 주소 (제안)

```
https://erp.swonbiz.com/kiosk/{roomId}?token={deviceToken}
```

로그인이 없으므로 **기기 토큰**으로 이 회의실의 오늘 예약(시간만)만 읽을 수 있게 합니다.
토큰 발급·폐기 화면은 회의실 설정(4차)에 들어갈 항목입니다 — 그 전까지는 운영자가 수동 발급.

### 주기

| 대상 | 주기 | 비고 |
|---|---|---|
| 데이터 | 30초 폴링 | 5초는 24시간 기준 하루 17,000회 요청. 반영 지연 최대 30초로 충분 |
| 시계 · 현재 시각 마커 · 배너 판정 | 1초, 로컬 시계 | 서버 요청 없음. 진입 시 받은 서버 시각으로 보정 |
| 자정 | 날짜 · 타임라인 리셋 | 다음 폴링에서 새 날짜 데이터 |

데이터가 바뀌면 화면 전체에 420ms 페이드만 (`kFade`). 레이아웃은 움직이지 않습니다.

### 화면 꺼짐 방지

`navigator.wakeLock.request("screen")`. 해제되면 5초 후, 실패하면 10초 후 재시도 (템플릿 코드 그대로).
기기 설정의 화면 자동 꺼짐·키오스크 모드는 설치 시 별도로 설정해야 합니다.

### 크기 규칙

1280×800 고정으로 제작했습니다. 다른 해상도는 원본 템플릿처럼 `clamp()` 와 `vw` 로 키우고 줄입니다 —
폭은 전부 %라 가로 스크롤은 생기지 않습니다. **세로 800px 미만**이면 다음 예약 영역(176px)이 먼저 빠듯해집니다.

## 9. 통신 끊김

| 끊긴 시간 | 표시 | 배너·타임라인 |
|---|---|---|
| 첫 폴링 실패 ~ 30분 미만 | 상단 빨간 스트립 「연결이 끊어졌습니다 · 마지막 갱신 13:35」 | **마지막 데이터 + 로컬 시계로 계속 판정** |
| 30분 이상 | 스트립 유지 | 배너 「현황을 확인할 수 없습니다」, 타임라인·카드 opacity .35 |
| 복구 | 스트립 제거, 페이드 | 정상 |

30분을 넘기면 그 사이 취소·추가된 예약이 반영되지 않아 **틀린 「비어 있음」** 을 보여줄 수 있습니다. 그래서 상태 판정을 멈춥니다.
폴링은 끊긴 동안에도 30초마다 계속합니다.

스트립: 높이 56px, `--color-danger-bg`, 테두리 `rgba(220,38,38,.3)`, `wifi-off` 22px + 22px/700 `--color-danger`.
