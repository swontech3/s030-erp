# 회의실 예약 화면 (s0300600010)

기준 폭 1440px. 셸은 `common/04-shell.md` 그대로 — 사이드바 「회의실」 활성.

```
┌ 사이드바 ┬─ 헤더 64px ── 운영 · 강남 삼성점 / 회의실 예약 ───── 권한 안내 │ 계정 ┐
│          ├─ 툴바 ──────────────────────────────────────────────────────────┤
│          │ [‹][오늘][›] 9월 28일 – 10월 4일      [회의실 A ▾] [월간|주간] [+ 예약 추가] │
│          ├─ 패널 (radius-lg, border) ───────────────────────────────────────┤
│          │  요일 헤더 56px (sticky)                                         │
│          │  시간 열 72px │ 월 │ 화 │ 수 │ 목 │ 금 │ 토 │ 일                   │
│          │  30분 = 28px 행 · 세로 스크롤                                    │
│          ├─ 범례 바 ───── 확정 · 종료 · 현재 시각 ······ 운영 09:00–22:00 · … ┤
└──────────┴─────────────────────────────────────────────────────────────────┘
```

---

## 1. 헤더

| 요소 | 규격 |
|---|---|
| 상단 캡션 | 12px `--text-caption` 「운영 · {지점명}」 |
| 제목 | 17px/700 「회의실 예약」 |
| 권한 안내 | 12px `--text-muted`, 1280 이상에서만. 운영자 「운영 관리자 · 전체 예약 내용 표시」 / 입주사 「입주사 · 타사 예약은 「예약됨」으로만 표시됩니다」 |

---

## 2. 툴바

좌: 이동 그룹 + 기간 · 우: 회의실 · 보기 전환 · 예약 추가. 모두 높이 36px, gap 12px.

| 요소 | 규격 · 동작 |
|---|---|
| ‹ / › | 36×36 아이콘 버튼. 주간 ±7일, 월간 ±1달, 767 이하 ±1일 |
| 오늘 | ghost sm. 오늘로 이동 + 현재 시각으로 스크롤 |
| 기간 | 17px/700 tabular. 주간 「9월 28일 – 10월 4일」(월이 바뀌면 「9월 28일 – 10월 4일」처럼 양쪽 월 표기), 월간 「2026년 9월」, 767 이하 「9월 30일 (수)」 |
| 회의실 Select | 좌측 `door-open` 16px + 「회의실 A (4~5인)」. 바꾸면 그리드 행·규칙 문구가 그 회의실 설정으로 다시 그려짐 |
| 월간 \| 주간 | 세그먼트. **운영자 + 768 이상에서만** 렌더 (입주사에게는 DOM 자체가 없음) |
| 예약 추가 | primary sm + `plus`. 767 이하에서는 숨기고 하단 고정 버튼으로 대체 |

**입주사 › 버튼 비활성** — 다음 주의 월요일이 예약 가능 마지막 날(오늘+27일)보다 뒤면 disabled.
지난 주로는 이동할 수 있습니다 (자기 이력 확인).

## 3. 주간 그리드

### 행·열

```
grid-template-columns: 72px repeat(7, minmax(0,1fr));   /* 768~1279: 56px */
행 수   = (회의실.close − 회의실.open) / 30
행 높이 = 28px   정시 실선 · 30분 점선 (border-top)
시간 라벨 = 정시만 12px --text-caption, 우측 정렬
```

행 범위는 **선택된 회의실의 운영시간**입니다. 회의실 B(08:00~20:00)로 바꾸면 24행, C(09:00~18:00)는 18행.

### 요일 헤더 (sticky)

높이 56px. 요일 12px/700 `--text-muted` + 날짜 16px/700.
오늘: 텍스트 `--color-primary`, 배경 `rgba(79,70,229,.03)`, 하단 20%~80% 2px 바. 오늘 열 본문에도 같은 배경.

### 칸 상태

| 상태 | 조건 | 표시 | 커서 |
|---|---|---|---|
| 빈 칸 | — | 투명, hover `rgba(79,70,229,.05)` | pointer |
| 지난 칸 | 칸 종료 ≤ 현재 | `--surface-alt` | 운영자 pointer · 입주사 not-allowed |
| 입주사 차단 · 지난 시각 | 칸 시작 < 현재 | `--surface-alt` | not-allowed, title 「지난 시각은 예약할 수 없습니다」 |
| 입주사 차단 · 4주 밖 | 날짜 > 오늘+27일 | 135° 사선 줄무늬 (`--surface-alt` / white 6px) | not-allowed, title 「10월 27일까지 예약할 수 있습니다」 |

> 현재 시각이 걸친 칸(13:30~14:00, 현재 13:40)은 입주사에게 **차단**입니다. 시작 시각이 이미 지났기 때문입니다.

### 예약 블록

`position:absolute; left:3px; right:3px; top = (start − open)/30 × 28 + 1; height = 칸수 × 28 − 2`

| 줄 | 조건 | 규격 |
|---|---|---|
| 시간 「16:00–17:00」 | 항상 | 11px/700 `--color-primary-hover` tabular |
| 제목 | 2칸 이상 (767 이하는 항상) | 12px/700 `--text-heading`, 말줄임. **타사는 「예약됨」** |
| 조직 · 인원 | 3칸 이상 + 내용 볼 수 있음 | 11px `--text-muted` 「오르카 스튜디오 · 5명」 |
| 「운영사」 뱃지 | 운영자 화면 + 운영사가 예약 조직 | 우상단 16px pill `--color-accent-bg` / `--color-primary-hover`. 768~1279 숨김 |

| 표시 상태 | 배경 | 좌측 3px |
|---|---|---|
| 확정 | `rgba(79,70,229,.08)`, hover `.14` | `--color-primary` |
| 종료 | `--surface-alt`, 텍스트 `--text-muted` | `--text-caption` |
| 취소 | **그리지 않음** — 그 시간은 빈 칸 | — |

타사 예약(「예약됨」)은 **확정 블록과 같은 모양**입니다 (템플릿 마스킹 그대로). 클릭해도 아무 일 없고 cursor 는 default.

### 현재 시각

오늘 열에만 1px `--color-accent` 선 + 좌측 8px 원. 운영시간 밖이면 그리지 않습니다.
1분마다 위치 갱신 (다시 그리지 말고 `top` 만).

### 범례 바

`--surface-alt`, 12px `--text-muted`. 좌측 범례 + 우측 규칙 문구 (`--text-caption`).

```
운영자  운영 09:00 – 22:00 · 30분 단위 · 1회 30분 ~ 4시간
입주사  운영 09:00 – 22:00 · 30분 단위 · 1회 30분 ~ 4시간 · 입주사 10월 27일까지 · 하루 2시간
```
「예약 가능 기간 밖」 범례는 입주사에게만.

## 4. 월간 (운영자 전용)

**운영자만 · 768 이상만.** 템플릿 결정 그대로입니다 — 월간은 가동률을 보는 용도라 입주사에게 필요 없고,
타사의 한 달치 사용 밀도는 노출하지 않는 편이 맞습니다. 입주사가 `view=month` 로 들어와도 주간으로 강제하고 서버도 막습니다.

### 전환

- 툴바 세그먼트 `월간 | 주간`. 두 보기는 **기준 날짜(anchor) 하나를 공유**합니다
- 주간 → 월간: anchor 가 속한 달
- 월간 → 주간: 세그먼트를 누르면 anchor 가 속한 주, **날짜 셀을 누르면 그 날짜가 속한 주**
- URL `view` · `date` 를 갱신해 새로고침·공유 시 유지

### 셀

월요일 시작 7열, gap 8px, 주 단위로 채움(앞뒤 달 날짜는 opacity .4, 클릭 불가). 최소 높이 112px.

```
┌──────────────┐
│ 30           │  16px/700 — 오늘은 30px 원 --color-primary / 흰 글자
│ ▓▓▓▓░░░░░░░  │  8px 트랙 #EEF0F4 + 채움 --color-secondary, 폭 = 예약 분 / 운영 분
│ 5건 · 5h     │  18px — 건수 600 --text-heading · 시간 400 --text-muted
└──────────────┘
```

- 선택된 회의실만 집계합니다. 취소 제외, 종료 포함
- 0건이면 트랙만 두고 텍스트 없음
- 셀에 조직명·제목은 넣지 않습니다. `title` 툴팁에 「11:00–13:00 한결세무법인」 줄 목록 (운영자 전용 화면이라 허용)
- 좁아서 넘치면 「5건 · 5h」 → 「5 · 5h」 → 「5h」 순으로 줄입니다 (템플릿 `fitCellLabel`)
- 지난 날짜 opacity .6
