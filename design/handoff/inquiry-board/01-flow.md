## 확정된 결정

| 항목 | 결정 |
|---|---|
| 제목 | 없음 — **문의 유형이 제목**입니다 (「입주문의」). 목록에 개인정보가 드러나지 않게 |
| 문의 유형 | 입주문의 · 법무설립문의 · 세무문의 · 연구소설립문의 · 기타 |
| 화면 형태 | 문의하기 · 비밀번호 확인 모두 **모달이 아닌 페이지** |
| 목록 | 2열 · 페이지당 20건 · 검색(문의일자 · 상태 · 문의유형) |
| 열람 | 로그인 대신 **글 비밀번호** |
| 운영자 답변 형태 | 글 답변 또는 **전화 답변 기록**(「전화로 답변드렸습니다」, 본문 없음) |
| 답변 알림 | **보내지 않습니다.** 운영자가 전화·이메일로 직접 연락. ERP 메일 발송 기능이 생기면 그때 추가 |
| 답변 수정·삭제 | **수정만.** 고치면 「2026.10.02 수정됨」 표시. 삭제 없음 |
| 추가 질문 | 같은 글에 이어 씀. **비밀번호로 들어온 사람만, 글 하나에 1회.** 운영자 답변과 시간순으로 쌓임 |
| 고객 글 수정·삭제 | 원글·추가 질문 모두 불가 (화면에 안내). 고쳐야 하면 추가 질문으로 이어 쓰거나 전화 |
| 스팸 | **같은 연락처 하루 3건 · 등록 후 1분 이내 재작성 차단.** 그 이상은 문제가 생기면 |
| 개인정보 6개월 | **자동 삭제하지 않습니다.** 운영자 화면에 「보관 기간 지남」 표시 → 운영자가 확인 후 삭제. 고객 화면에는 표시 없음. 동의 문구 「6개월 보관 후 파기」 |

「알림을 보내지 않는다」는 화면 문구에도 반영했습니다 — 대기 카드에 「별도 알림은 보내지 않으니 이 글에서 확인해 주세요」.
