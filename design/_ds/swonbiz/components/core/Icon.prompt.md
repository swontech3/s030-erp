One-line: the only icon primitive — inlines the Lucide set (CDN) at 1.5px stroke, inheriting currentColor.

```jsx
<Icon name="shield-check" size={20} />
<Icon name="sparkles" size={16} style={{ color: "var(--color-accent)" }} />
```

Sizes: 16 (inline/caption), 20 (default, buttons), 24 (feature bullets). Never emoji, never a hand-drawn SVG.
